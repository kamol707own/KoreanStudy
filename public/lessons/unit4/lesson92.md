## The Many Meanings of ~도록

~도록 is added to the stem of a verb (less commonly, an adjective) to express the purpose or intention of an action. Its meanings overlap with ~게, and ~도록 itself can mean "so that," "in order to," or "to make sure that."

### In Order To / So That

When used with verbs like 하다, 노력하다 or 애쓰다, ~도록 indicates the purpose of the action:

- **학생들이 이해하도록 설명했어요** = I explained it so that the students could understand
- **늦지 않도록 서둘러서 갔어요** = I hurried so that I wouldn't be late
- **잊어버리지 않도록 메모했어요** = I wrote a memo so that I wouldn't forget

### ~도록 하다: To Make Sure To

~도록 하다 is a very common expression that tells somebody to do something, similar to "~해라" or "~하기 바란다":

- **매일 운동하도록 하세요** = Make sure to exercise every day
- **밥을 먹기 전에 손을 씻도록 하세요** = Make sure to wash your hands before eating
- **내일까지 끝내도록 하겠습니다** = I will make sure to finish it by tomorrow

### ~도록 되다: To Be Made To / To Come To Be

~도록 되다 indicates that something has been set up or arranged (often by an outside force or circumstance) so that an action happens:

- **매주 금요일에 보고서를 쓰도록 되어 있어요** = It is set up so that I write a report every Friday
- **제가 그 일을 맡도록 되었어요** = It was arranged so that I take on that task
- **10시가 되면 문이 닫히도록 되어 있다** = The door is set up to close at 10 o'clock

### Purpose Affecting Someone Else

When the purpose is about another person's (or a machine's) action, ~도록 attaches to that action:

- **아이가 잘 자도록 조용히 해주세요** = Please be quiet so the child can sleep well
- **기계가 멈추지 않도록 계속 손을 대지 마세요** = Don't touch it so that the machine doesn't stop

### ~도록 vs ~게

~도록 and ~게 are often interchangeable when expressing purpose:

- **잘 들리도록/잘 들리게 크게 말했어요** = I spoke loudly so that it could be heard well

However, only ~도록 can be used in fixed expressions like ~도록 하다 and ~도록 되다.
