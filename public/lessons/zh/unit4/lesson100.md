## 会：~ㄹ/을 텐데(요)

텐데 是通过合并伪名词 터 + 이다 + ~ㄴ/은데 创建的。 터 提供期望或猜测的含义。

### 如果...（过去时，遗憾）

~ㄹ/을 텐데 与假设的过去时一起使用时会增加**遗憾**的感觉：

- **날씨가 좋았더라면 저는 공원에 갔을 텐데요** = 如果天气很好，我就会走了（但事实并非如此）
- **제가 돈이 있었더라면 그것을 샀을 텐데요** = 如果我有钱，我就会买那个

### 即使……（烦恼）

~ㄹ/을 텐데 使用 ~더라도 添加 **烦恼** 的感觉：

- **날씨가 좋았더라도 저는 공원에 안 갔을 텐데요** = 呃，就算再好我也不会去

### 如果...（现在时，“太糟糕了”）

- **음식이 더 있으면 좋을 텐데** = 哦，可惜没有更多食物了

### 更多示例

- **지금 안 가면 그 품목이 없을 텐데** = 如果我们现在不走就不会有任何物品
- **주사를 안 맞았더라면 팔이 가렵지 않았을 텐데** = 如果我没有接种疫苗，我的手臂就不会痒
- **큰길로 갔더라면 모임에 늦게 도착하지 않았을 텐데** = 如果我们走主路，我们就不会迟到

## 可能是：~ㄹ/을 텐데(요)

当说话者假设或期望某事时使用。比~ㄹ/을 것 같다稍微确定一点，带着一点担心的感觉。

- **비가 올 텐데** = 可能会下雨（我有点担心）
- **날씨가 추울 텐데** = 天气可能会变冷
- **그 식당이 이미 닫았을 텐데** = 餐厅可能已经关门了（这太糟糕了）

---

## 在一句话的中间

~ㄹ/을 텐데 连接两个子句，意思是“it is probable that... so”：

- **길이 막힐 텐데 지하철로 가자** = 路上可能会堵车，所以我们坐地铁吧

~ㄹ/을 테니까 在表达**意图**时类似且更自然：

- **지금 갈 테니까 조금 더 기다려 주세요** = 我现在要走了，请稍等一下
- **제가 돈을 많이 벌 테니까 걱정하지 마세요** = 我会赚很多钱，所以别担心
