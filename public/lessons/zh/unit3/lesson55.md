## 用주다“:~달라고”引用的命令式句子

当原发言人要求将某物交给其本人，或要求为其做某事时，若使用了~주다，则주다应将其替换为달다。

- 휴지를 달라고 했어요 = 我说：“请给我一张纸巾。”
- 맥주 한 병을 달라고 했어요 = 我说：“请给我一瓶啤酒。”
- 엄마가 숟가락과 칼을 달라고 했어 = 妈妈说：“请给我一把勺子和一把刀。”
- 우리 아들은 계속 용돈을 달라고 졸라요 = 我们儿子总是一直缠着要零花钱
- 부장은 사원에게 창고에 있는 자전거를 달라고 했어요 = 老板对员工说：“从仓库拿辆自行车给我。”

달다 在请求执行某项操作时，也可以用주다“~아/어 주다”代替“”：
-  =저의 머리카락을 꼬지 말아 달라고 했어요 我告诉她，请别再拧我的头发了
-  학생은 선생님에게 성적을 올려 달라고 했어요= 学生对老师说：“把我的分数提高一点”
-  다음 주에 입주할 거라서 그때 와 달라고 했어요= 我们下周要搬进新家，所以我让他们那时再来
-  어떤 공무원이 우리 집에 와서 설문조사를 답해 달라고 했어요= 有位政府工作人员来我们家，要求我们填写一份调查问卷
-  부장님은 우리회사가 행사를 개최할 때 끝까지 애써 달라고 했어요= 举办这次活动时，老板要求我们尽最大努力

> **Note:** ~(으)라고 can still be added to 주다 if the original speaker asks for an object to be given to somebody else.

## 请求： 부탁

부탁 意为“帮忙”或“请求”。 부탁하다意为“请求帮忙”或“提出请求”。

- 저는 부탁이 하나 있어요 = 我有个请求 / 我有个要求）
- 남편에게 청소를 부탁했어요 = 我让丈夫负责打扫卫生
- 밥을 빨리 만들어 달라고 부탁했어요 = 我让他快点煮饭

> **注：**  通常부탁하다读作 부탁(을) 드리다。
-  밥을 빨리 만들어 달라고 부탁 드렸어요= 我让他快点煮饭
