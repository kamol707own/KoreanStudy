## 简介

在本课程中，您将了解单词 **유일하다**，它可用于创建“仅”的含义。在第 12 课中，您学习了助词 **~만**，它也可用于创建“仅”的含义。然而，유일하다和~만的用法是不同的。

---

## 仅：유일하다

“유일하다”这个词是一个形容词。形容词通常放在名词之前来描述它们。

- 코끼리 = 大象 → 큰 코끼리 = 大大象
- 토끼 = 兔子 → 귀여운 토끼 = 可爱的兔子

** ~만 和 유일하다 之间的主要区别：**

- **~만** 附加在名词上。当使用 ~만 时，并不表明该名词与任何其他名词是唯一的。
  - 나는 사과만 샀어 = 我只买了苹果

- **유일하다** 以一种使名词独特或突出的方式描述名词。这意味着它是唯一具有某种特殊品质的名词。
  - 나는 유일한 사과를 샀어 = 我买了唯一/唯一的苹果

**与 ~는 것 一起使用：**

You can describe a noun using verbs with **~는 것**. The noun being described by 유일하다 is also described by another verb using ~는 것.

- 먹는 사람 = 正在吃饭的人
- 먹는 유일한 사람 = 唯一正在吃饭的人
- 공부하는 사람 = 正在学习的人
- 공부하는 유일한 사람 = 唯一正在学习的人

**例句：**
- 저는 아직 먹고 있는 유일한 사람이라서 부끄러워요 = 我很害羞，因为我是唯一/唯一还在吃东西的人
- 오늘이 휴일이라서 제가 학교에서 공부하는 유일한 사람이에요 = 今天是假期，所以我是今天唯一/唯一在学校学习的人
- 저는 그 가게에서 파는 유일한 장갑을 샀어요 = 我买了那家商店唯一出售的手套
- 제가 먹고 싶은 유일한 음식은 삼겹살입니다 = 我唯一想吃的东西是삼겹살
- 제가 하고 싶은 유일한 것은 밥을 먹는 것이에요 = 我现在唯一想做的就是吃饭

**副词形式：유일하게**

也可以将 **~게** 附加到 유일하다 并将其用作副词。在这些情况下，它通常放在描述动词之前。

- 제가 유일하게 먹고 싶은 음식은 삼겹살입니다 = 我唯一想吃的食物是삼겹살
- 제가 유일하게 하고 싶은 것은 밥을 먹는 것이에요 = 我唯一想做的就是吃饭

**带形容词：**

当名词同时由形容词和유일하다描述时，最好将“유일한”更改为“유일하게”：

- 행복한 사람 = 快乐的人 → 유일하게 행복한 사람 = 唯一快乐的人
- 예쁜 여자 = 漂亮女孩 → 유일하게 예쁜 여자 = 唯一的漂亮女孩

**带有形容词的例句：**
- 이 방에서 유일하게 예쁜 여자는 저 여자예요 = 这个房间里唯一漂亮的女孩就是那个女孩
- 제가 바다에서 유일하게 무서운 것은 상어예요 = 在海洋中我唯一害怕的是鲨鱼
- 회사에서 유일하게 입을 수 있는 복장은 정장이에요 = 你在工作时唯一可以穿的东西/衣服是西装
- 그 아이가 우리 반에서 유일하게 이기적인 학생이에요 = 那孩子是我们班唯一自私的学生
