## 只不过/只有：~밖에

**“밖”** 一词具有“外部”的含义。它可以用作句子中的地点来指户外，或描述某物在特定区域的“外部”。

当 **~밖에** 作为助词附加到名词上时，说话者表示只有该名词（除了该名词之外什么都没有）受到作用。常见的翻译是“只不过”。

**示例：**
- 친구밖에… = 除了朋友什么都没有
- 밥밖에… = 除了米饭什么都没有
- 만 원밖에… = 只不过是 10,000 韩元

这类似于助词 **~만**，它的意思是“仅”。然而，当使用 ~밖에 时，说话者强调的是“除了”某个特定名词之外。

> **重要提示：** 当 ~밖에 附加到名词以具有此含义时，最后的动词应该是 **否定词**。这些句子通常以 없다 结尾。

**示例：**
- 저는 친구밖에 없어요 = 除了朋友我什么都没有
- 우리가 먹을 것은 밥밖에 없어요 = 我们除了米饭什么都没有吃
- 유행을 따라가는 사람들이 청소년들밖에 없어요 = 追随潮流的只有年轻人
- 그거를 사고 싶지만 만 원밖에 없어서 못 사요 = 我想买那个，但我只有一万韩元，所以买不到

> **注：**如果翻译稍有不同，您会发现与“outside”的含义相似：
> - 저는 친구밖에 없어요 = 除了朋友之外，我一无所有

**使用计数器或하나：**
- 저는 친구가 세 명밖에 없어요 = 我除了三个朋友什么都没有
- 저는 신용카드가 하나밖에 없어요 = 我除了一张信用卡什么都没有

**与其他动词（不仅仅是없다）：**

尽管 (名词)밖에 结构翻译为“除了（名词）之外什么都没有”，该句子应该以否定词形变化结尾。这通常会让说英语的人看起来像是双重否定。

- 코치가 우리 팀에게 충고를 하나밖에 안 했었어요 = 教练只给了我们一个建议
- 남자 친구가 너한테 돈밖에 안 줬다고？ = 你男朋友除了钱什么也没给你？
- 아빠가 배추를 하나밖에 주문하지 않았어요 = 爸爸只点了一颗（一头）卷心菜
- 제가 아는 공연 종류는 연극밖에 없어요 = 我所知道的唯一表演类型是戏剧
- 선생님! 저에게 답안지밖에 안 주셨어요 = Teacher! You only gave me an answer sheet
- 그 선생님의 수업을 한번밖에 참관하지 않았어요 = 我只上过这位老师的课一次
- 저는 평생 동안 오렌지를 세 번밖에 안 먹어 봤어요 = 我一生只吃过三次橙子

**强调短时间：**
- 30 분밖에 안 걸려요！ = 只需要30分钟
- 한 시간밖에 안 걸려요 = 只需要 1 小时

## 我无能为力，只能……：~ㄹ/을 수밖에 없다

In Lesson 45 you learned about the endings **~ㄹ/을 수 있다** and **~ㄹ/을 수 없다**. By attaching **~밖에** to 수 in "~할 수 없다" you describe that the best/only option is to do the specified action.

**翻译：**“别无选择，只能……”

**示例：**
- 우리가 밥을 먹을 수밖에 없어요 = 我们别无选择，只能吃饭
- 우리가 연극을 다른 데에서 할 수밖에 없어요 = 我们别无选择，只能在不同的地方进行比赛
- 죄송하지만 저는 당신을 해고할 수밖에 없어요 = 抱歉，除了解雇你我无能为力
- 쓰레기가 많아서 방을 싹 청소할 수밖에 없어요 = 我别无选择，只能彻底打扫房间
- 일이 너무 심심해서 다른 분야로 옮길 수밖에 없어요 = 我别无选择，只能移动/切换字段
- 시험을 네 번 연속으로 못 봐서 포기할 수밖에 없어요 = 我别无选择，只能放弃
- 내일도 비가 올 거라서 연극을 또 취소할 수밖에 없어요 = 明天又下雨，所以我们只能取消比赛
- 친구가 늦게 올 거라고 해서 우리는 기다릴 수밖에 없어요 = 我们的朋友说他会迟到，所以我们只能等待
- 내일 해변에 갈 거라서 겨드랑이 털을 면도할 수밖에 없어요 = 明天要去海边，只好剃腋毛了
- 오랫동안 운동해서 에너지를 다 소모해서 밥을 많이 먹을 수밖에 없어요 = 我运动了很长时间，耗尽了所有的精力，所以我只能吃很多食物
