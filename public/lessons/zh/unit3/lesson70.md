## 简介

在本课程中，您将学习如何将 **~아/어(서)** 应用于句子。解释这个概念可能是所有语法形式中最困难的，因为它的含义是如此微妙。

---

## 内在时间关系：~아/어(서)

当 **~아/어(서)** 用于连接两个子句时，第一个子句中的动作和第二个子句中的动作按照它们所说的顺序发生。这与使用 **~고** 时相同，但使用 ~고 时操作之间不需要直接连接。

然而，当您使用 **~아/어(서)** 时，两个子句之间更有可能存在内在关系 - 不仅第二个操作发生在第一个操作之后，而且第二个操作发生是因为第一个操作允许它发生。

**示例：**
- 저는 학교에 가서 공부할 거예요 = 我会去学校然后学习
- 우리는 집에 와서 바로 잤어요 = 我们回家后立即入睡

**带有 ~아/어 和 ~아/어서 的示例（含义相同）：**
- 새로운 컴퓨터를 사 작업을 했어요 / 새로운 컴퓨터를 사서 작업을 했어요 = 我买了一台新电脑，然后开始工作
- 케이크를 만들어 친구들에게 나눠 줬어요 / 케이크를 만들어서 친구들에게 나눠 줬어요 = 我做了一个蛋糕，然后把它送给了我的朋友
- 서랍을 열어 돈을 찾았어요 / 서랍을 열어서 돈을 찾았어요 = 我打开抽屉然后找到了钱

> 在上述所有情况下，**~고** 可以替换 **~아/어(서)**。如果您认为两个子句之间存在内在联系，则更有可能发现使用 ~아/어(서)。

---

## 一个动作通过另一个动作发生：~아/어서

**~아/어서** 可以附加到动词后，表示第二个动作“如何”或“通过什么方式”发生。

- 저는 걸어서 집에 갔어요 = 我步行回家（我步行回家）

> **重要提示：** 在 ~아/어서 用于指示“方法”或“手段”的此类句子中，“서”**不是可选的**。

**示例：**
- 슬기가 몸을 쭈그려서 예쁜 꽃의 향기를 맡아봤어요 = Seulgi蹲下来闻着美丽的花香
- 제가 당신을 위해 정성 들여서 만든 음식입니다 = 这是我用我所有的爱/努力为你做的食物
- 대통령이 연설을 해서 청중을 사로잡았다 = 总统通过演讲吸引了观众
- 저는 전력을 다해서 이 일을 내일까지 마무리해 볼 거예요 = 我将使用我所有的力量并争取在明天之前完成这项工作
- 지구본을 사용해서 지도를 그렸어요 = 他用地球仪画了地图
- 우리는 힘을 다 합해서 일을 마무리했어요 = 我们齐心协力完成了这项工作

> **注意：** ~아/어서 和 ~아/어(서) 的用法之间有很多重叠。含义通常由说话者阐明或由听者解释。

---

## 用于组合两个单词的含义：~아/어

您经常会看到两个单词与 **~아/어** 组合在一起以组合它们的含义。当这样使用时，不附加“서”。

**组合动词的例子：**
- 걸어가다 = 步行前往 (걷다 + 가다)
- 걸어오다 = 步行前来 (걷다 + 오다)
- 뛰어다니다 = 围绕某个区域奔跑 (뛰다 + 다니다)
- 돌아보다 = 转身看 (돌다 + 보다)
- 알려주다 = 让某人知道 (알리다 + 주다)
- 지켜보다 = 通过观看进行保护 (지키다 + 보다)
- 비켜서다 = 站立/退到一边 (비키다 + 서다)
- 올려놓다 = 将某物放置在某物上 (올리다 + 놓다)
- 뛰어가다 = 运行到 (뛰다 + 가다)
- 달려가다 = 运行到 (달리다 + 가다)
- 뛰어오다 = 通过运行 (뛰다 + 오다)
- 달려오다 = 通过运行 (달리다 + 오다)

**例句：**
- 아이들이 놀이터에서 뛰어다녔어요 = 孩子们在操场上奔跑
- 방에 들어가서 책을 책상에 올려놓았어요 = 我走进房间，把书放在桌子上
- 너무 늦어서 학교에 뛰어갔어요 = 我很晚了，所以我跑去学校
- 너무 늦어서 학교에 달려갔어요 = 我很晚了，所以我跑去学校

**两个单独的动词与 ~아/어 组合（带空格）：**
- 걸어 다니다 = 在某个区域中走动
- 돌려 보내다 = 发回一些东西
- 뛰어 넘다 = 跑/跳过某物
- 꺼내 놓다 = 取出并放下
- 아껴 쓰다 = 保存一些东西
- 걷어 올리다 = 卷起袖子/裤子

## 통하다 的多种含义

**“통하다”** 这个词根据具体情况有多种含义。大多数这些含义都与两个事物相连，以及它们之间存在通道或流动有关。

- 이 방은 공기가 잘 안 통해요 = 此房间内空气流通不佳
- 이 식당에 옆 식당과 통하는 길이 있어요 = 有一条路连接这家餐厅和隔壁的餐厅
- 그 사람과 말이 안 통해서 그 사람을 이해할 수 없어요 = 我听不懂那个人的意思
- 한국에서 그 여자가 제일 예쁜 가수로 통한다=那个女孩被誉为韩国最漂亮的歌手

**통해(서) 表示“通过”：**

- 불이 나고 문이 막혀 있어서 창문을 통해 빠져나갔어요 = 我从窗户逃走了
- 교과서를 통해서 그 사실을 배웠다 = 我通过那本书了解到了这个事实
- 친구를 통해 소문을 들었어요 = 我从/通过我的朋友听到了谣言
- 저는 저의 여자 친구를 통해 한국말을 배웠습니다 = 我通过女朋友学韩语

## 快点：서두러

动词 **"서두르다"** 的意思是“匆忙”，可以用作独立动词，也可以用在与 **~아/어(서)** 连接的另一个动词之前。

- 우리는 서둘러 나갔어요 = 我们赶紧跑出去
- 선생님은 서둘러 학생들에게 수업을 가르쳤요 = 老师赶紧给学生上课
