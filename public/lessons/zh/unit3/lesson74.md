## 简介

在本课程中，您将学习如何在句子中使用单词**“상관없다”**，既可以作为可以放在句子末尾的单词，也可以作为副词放在句子中间。

---

## 如果……也没关系：상관없다

“상관”这个词字面意思是“关系”，而说“상관없다”则表明两个事物之间没有关系。

**简单使用：**
- 第一个人：내일 언제 가고 싶어요？ = 明天你想什么时候去？
- 第二个人：상관없어요 = 没关系/我不在乎
- 第一个人：짐을 어디에 둬야 돼요？ = 我应该把行李放在哪里？
- 第二个人：상관없어요 = 没关系/我不在乎

**与~아/어도：**

将 **~아/어도**（第 49 课）附加到“不相关”的子句中：
- 네가 배고파도 상관없어 = 如果你饿了也没关系
- 우리는 거기에 가도 상관없어 = 我们是否去那里并不重要
- 그게 비싸도 상관없어 = 贵也没关系
- 그것을 먹어도 상관없어요 = 你吃不吃没关系
- 발이 부어 있어도 상관없어요 = 脚肿了也没关系
- 선물을 안 사도 상관없어요 = 不买礼物也没关系
- 시골에서 살아도 상관없어요 = 即使我住在乡村也没关系
- 맨발로 들어와도 상관없어요 = 如果你赤脚进来也没关系

**带有疑问词（~는지 或 ~든지）：**

当您想要包含疑问词时，附加 ~아/어도 是不自然的。使用 **~는지** 或 **~든지** 代替：
- 우리가 언제 갈지 상관없어요 = 我们什么时候去并不重要
- 우리가 어디 갈지 상관없어요 = 我们去哪里并不重要
- 우리가 언제 가든지 상관없어요 = 我们什么时候去并不重要
- 우리가 어디 가든지 상관없어요 = 我们去哪里并不重要
- 운전면허를 언제 받을지 상관없어요 = 你什么时候拿到驾照并不重要
- 학생들이 어떻게 반응할지 상관없어요 = 学生的反应并不重要

**与 ~거나 （或者）：**

将 **~거나** 添加到两个选项，然后添加 상관없다：
- 우리가 먹거나 안 먹거나 나는 상관없어 = 我们吃或不吃对我来说并不重要
- 돈을 벌거나 잃거나 나는 상관없어 = 赚钱或赔钱对我来说并不重要
- 내일 주식이 떨어지거나 오르거나 상관없어요 = 明天股票下跌或上涨并不重要

## 不管…：상관없이

您可以使用 **상관없이** 作为副词来表达“无论......”的含义

**带有名词（使用 ~와/과/하고/랑/이랑）：**
- 추위와 상관없이 = 无论寒冷
- 날씨와 상관없이 = 无论天气如何
- 통증과 상관없이 = 不管疼痛
- 저의 건강과 상관없이 = 无论我的健康状况如何
- 운과 상관없이 = 不管运气如何
- 국적과 상관없이 = 不限国籍

**例句：**
- 추위와 상관없이 저는 밖에 나갈 거예요 = 不管寒冷，我都要出去
- 날씨와 상관없이 우리는 지금 가야 돼요 = 不管天气如何，我们现在就出发
- 통증과 상관없이 곧 일어나야 될 거예요 = 不管有多痛，你都得尽快起床
- 국적과 상관없이 부상자들은 모두 동등하게 치료를 받아야 돼요 = 不分国籍，所有受伤者都需要得到公平对待

**带子句 (~는지)：**
- 제가 돈을 얼마나 많이 가지고 있는지 상관없이 여자 친구를 위해 비싼 선물을 사야 돼요 = 不管我有多少钱，我都要给女朋友买件昂贵的礼物

> **注意：** 当您在两个子句中间使用 ~아/어도 或 ~든지 时，它们本身具有“无论”或“是否”的含义。因此，包含 상관없이 是多余的。

## 尽管：~ㅁ/음에 불구하고

另一个具有类似含义的单词是**불구하다**，几乎只用在句子中间。

**在名词之后（带有 ~에도）：**
- 날씨에도 불구하고 = 尽管天气恶劣
- 통증에도 불구하고 = 尽管很痛
- 날씨에도 불구하고 경기를 직접 보는 팬들이 열광했어요 = 尽管天气恶劣，现场观看比赛的球迷仍然热情高涨
- 통증에도 불구하고 마취 없이 소화기관에 수술을 받았어요 = 尽管疼痛，他还是在没有麻醉的情况下对消化器官进行了手术

**在动词/形容词之后 (~ㅁ/음)：**
- 그럼에도 불구하고 점수가 너무 낮아서 학점을 못 받아요 = 尽管如此，你还是无法获得积分，因为你的分数太低
- 어제 여자 친구에게 차였음에도 불구하고 오늘 자신감이 있어요 = 尽管昨天分手了，但今天我充满信心

> **注意：** ~ㅁ/음에도 불구하고 最常用于书面韩语。
