## 简介

在本课程中，您将了解 **"대신,"** 这个词如何使用，它可以通过几种不同的方式使用来表达“相反”的含义。

---

## 相反：대신(에)

**~에**在使用时通常附加在대신后面。

**简单名词用法：**
- 밥 대신에 =代替米饭
- 연필 대신에 = 代替铅笔
- 우유 대신에 =代替牛奶
- 머리핀 대신에 = 代替发夹
- 부피 대신에 = 代替音量

**例句：**
- 저는 밥 대신에 빵을 먹었어요 = 我没有吃米饭，而是吃了面包
- 저는 연필 대신에 펜을 쓸 거예요 = 我不使用铅笔，而是使用钢笔
- 애기는 우유 대신에 물만 마시고 싶어요 = 宝宝只想喝水而不是牛奶
- 머리핀 대신에 머리띠를 주세요 = 给我发带而不是发夹
- 부피 대신에 가로만 재 보세요 = 不测量体积，仅测量宽度

**对于操作（使用 ~는 것）：**

如果你想表达一个人做了一个动作而不是另一个动作，有两种方法：
1. 밥을 먹는 것 대신에
2.밥을 먹는 대신에

两者的含义完全相同，韩国人无法区分。

**例句：**
- 지금 가는 것 대신에 자정 후에 나가자 = 现在不走，我们午夜过后出去吧
- 먼지 때문에 밖에 나가는 것 대신에 집에 있자 = 因为灰尘，我们不出去，呆在家里吧
- 안산에서 사는 것 대신에 의정부에서 살고 싶어요 = 我不想住在安山，而是想住在议政府市
- 그냥 앉아 있는 것 대신에 헬스장에 가서 운동하자！ = 我们不只是坐在这里，去健身房锻炼吧！
- 몸 상태가 안 좋아서 친척을 보러 가는 것 대신에 집에 있을 거예요 = 我的身体状况不好，所以我不会去看望亲戚，而是呆在家里
- 와이프를 집사람이라고 부르는 것 대신에 아내라고 부를 거예요 = 我不会称呼我的妻子为“家庭主妇”，而是称呼她为“妻子”
- 아플 때 식은땀을 흘리면 뜨거운 샤워를 하는 것 대신에 차가운 샤워를 해야 돼요 = 当你生病时，如果出冷汗，不应该洗热水澡，而应该洗冷水澡

> **重要提示：** 在所有示例中，始终使用 ~는 것 的 **现在时**。即使您谈论的是过去或将来的事情，也始终使用 ~는 것 대신에。

## 차라리

**“차라리”** 这个词在句子中强化了一种感觉，即一个人正在谈论做一个动作而不是另一个动作。它经常与“대신에”一起使用。

**示例：**
- 第一个人：학교에 갈래요？ = 我们去学校吧？
- 第二个人：차라리 오락실 가자！ = 与其这样，我们去游乐场吧！

**대신（没有에）可以达到相同的目的：**
- 第一个人：밖에 나갈래요？ = 我们出去一下吧？
- 第二个人：대신 여기서 있자 = 我宁愿留在这里

---

## 相反：~말고

您可以使用 **"말고"** （而不是使用 ~지 말고 与动词）来获得与仅使用 대신 与名词类似的含义。

- 밥 말고 빵 먹을래요？ = 我们可以不吃米饭，吃面包吗？
- 소문 말고 확실한 증거가 필요해요 = 我们需要证据，而不是谣言
- 지금 말고 자정 무렵에 가는 게 어때요？ = 现在不行，午夜左右去怎么样？
- 우유 거품 말고 진짜 우유를 많이 주세요 = 请给我真正的牛奶，而不是奶泡/泡沫
- 이 수영장은 동절기 말고 하절기에만 열어요 = 该游泳池仅在夏季开放，冬季不开放

> **注意：** 某些重音符号会将“말고”更改为“말구”。年轻人也会说“말구”来听起来很可爱。
