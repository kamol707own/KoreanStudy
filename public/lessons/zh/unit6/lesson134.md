## 将英语和韩语结合起来的词

- **헬기** =螺旋(缩写)+ 기 (机器)=直升机
- **믹서기** = 搅拌机+ 기 (机器)=搅拌机
- **드럼세탁기** + 鼓声+ 세탁기 (洗衣机) = 前置洗衣机
- **골프장** =高尔夫+ 장 (地点)=高尔夫球场
- **트레이닝복** = 培训+ 복 (衣服) = 训练服
- **셀카봉** = 自拍 + = (帮助) 봡 (棍子)=自拍棒(自拍棒)
- **싱크대** = 汇+ 대 (办公桌)=水槽
- **노잼** = 无 + 재미 (乐趣)=不好笑
- **팀장** =团队+ 장 (主管/领导)=组长
- **왕팬** = 왕 (金)+扇子=一个大扇子
