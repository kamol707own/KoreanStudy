## 导言

在这个课中,你会学会如何添加~별 和它创造的意义。 你会看到它经常附着在名词上来描述另一个名词,或者用~로 作为副词。

## 要分组或分类为:~별

~ ~ 说吧 ~별 添加到代表一个以上类型或层次的名词中。 完成后,它会将不同的类型/级别分类,并表明每个类型/级别都做了一些事情(单独).

实例:
- 수준 = 职等 = **수준별**: 每一级将单独做一些事情
- 성 =性别 = **성별**: 将性别分类
- 학년 = 学校年级 = **학년별**: 职等将予分类
- 부서 =部门 = **부서별**部门将予分类
- 개인 =个人,个人 = **개인별**: 个人将被分类
- 국가 =国家 = **국가별**: 将国家分类

这些构件经常放在其他名词之前来描述:
- **수준별 수업** = 按级别划分的类别
- **성별 임금 차이** = 男女工资差别
- **학년별 명단** =根据年级列出的学生名单
- **부서별 회의** = 各部开会
- **개인별 평가** = 对每个个人进行的评价
- **국가별 언어 설정** = 每个国家的语言设置

### 示例句子
- 수준별 수업은 좋은 점도 있고 나쁜 점도 있어요 =按等级划分的班次也有好分和差分.
- 대부분 회사에는 성별 임금 차이가 있어요 = 在大多数公司,男女工资有差别。
- 개학 전에 우리는 학년별 명단을 작성해야 돼요 =开学前,需要按年级列出学生姓名.
- 연말이라서 부서별 회식이 많아요 年终了,所以各部门之间有很多员工晚餐
- 새로운 컴퓨터를 사면 국가별 언어 설정을 해야 돼요 = 购买新计算机时,需要设置语言设置.

### 使用 ~별

~ ~ 说吧 ~별로 通常用于表示动作会因指定的类型/级别而有所不同。

- 우리 회사는 분기별로 세금을 내요 我们公司按季度缴税
- 코치가 선수들을 체중별로 나눴어요 = 教练按重量将运动员除以
- 저는 신분증을 나이별로 다 정리했어요 我按年龄整理了身份证
- 모든 나라가 국가별로 대표를 지명했어요 = 每个国家分别指定一名代表。
- 대륙별로 발견된 공룡들의 무게는 달랐어요 恐龙的重量因大陆而异
- 사람의 평균 월급은 보통 계급별로 다릅니다 = 个人平均工资因类别不同而不同。
- 한국에서는 영어와 수학수업이 보통 수준별로 나눠져요 = 在韩国,英语和数学课通常按级别划分.
