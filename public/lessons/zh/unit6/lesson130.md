# 第 130 课: 不得不、只能: ~ㄹ/을 수밖에 없다

## 词汇

### 名词
- **상황** = 状况、情况
- **결과** = 结果
- **선택** = 选择
- **현실** = 现实
- **포기** = 放弃
- **실패** = 失败
- **수단** = 手段、方法

### 动词
- **포기하다** = 放弃
- **인정하다** = 承认
- **받아들이다** = 接受
- **선택하다** = 选择

### 形容词
- **불가피하다** = 不可避免的

## 介绍

在本课中，您将学习如何使用 ~ㄹ/을 수밖에 없다 来表达“除了……之外别无选择”或“只能/不得不做某事”。

## 表达“不得不/只能”: ~ㄹ/을 수밖에 없다

~ㄹ/을 수밖에 없다 接在动词或形容词词干后面。它由以下两部分组合而成：
- ~ㄹ/을 수 있다/없다 (能够 / 不能)
- ~밖에 (除了……之外)

组合在一起时，字面意思是“除了做 [动词] 之外没有其他办法/途径”。

### 例句

- 지금 상황에서는 그 계획을 **포기할 수밖에 없어요**.
  = 在目前的情况下，我们不得不放弃那个计划。

- 비밀이 밝혀졌으니 사실을 **인정할 수밖에 없어요**.
  = 既然秘密已经暴露，我只能承认事实。

- 버스가 이미 떠나서 택시를 **탈 수밖에 없었어요**.
  = 公交车已经开走了，我只能坐出租车。

- 너무 열심히 공부했으니까 시험에 **합격할 수밖에 없어요**.
  = 她学习太努力了，考试必然会通过。

- 아무도 돕지 않아서 혼자 **할 수밖에 없어요**.
  = 没有人帮忙，我只能一个人做。
