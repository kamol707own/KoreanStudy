## 在往返…的路上：~는 길이다

至此，您可能已经非常熟悉如何在韩语中使用 길 一词了。它翻译为“街道”或“道路”：

- 제가 저 길에서 살아요 = 我住在那条路上
- 이 길의 이름이 뭐죠？ = 这条路/街道的名称是什么？
- 어떤 길을 찾고 있습니까？ = 你在寻找哪条路？

除了这个简单的含义之外，当用作〜는 것原则中的名词时，**길可以具有不同的含义**。当길由前面的短语描述时，我们可以表达某人**正在去往或离开某个地方的路上**。

### 示例：

- 제가 집에 **가는 길** Been on my way (going home) = 我正在回家的路上
- 제가 회사에서 **오는 길** Been 에요 = 我正在下班途中

### 这个语法原则只适用于来或去的动词：

- 들어가다 = 进入
- 들어오다 = 进来
- 나가다 = 出去
- 나오다 = 出来
- 내려가다 = 向下
- 내려오다 = 下来
- 올라가다 = 上升
- 올라오다 = 出现
- 돌아가다 = 返回
- 돌아오다 = 回来

### 更多示例：

- 제가 산을 **올라가는 길** Been on my way (going) 上山
- 지금 회사에서 **나오는 길** Been 에요 = 我正在离开办公室的路上
- 우리는 경기장에 **들어가는 길** Been 에요 = 我们正在（在路上）进入体育场
- 이가 매일 시려서 이제 치과에 **가는 길** Been 에요 = 我的牙齿每天都酸痛，所以我现在正在去看牙医的路上
- 약을 과다하게 복용해서 부작용 때문에 병원에 **가는 길** Been 에요 = 我服用了太多药物，由于副作用，我正在去医院的路上
- 어제 산 옷이 너무 헐렁해서 교환하러 **가는 길** Been 에요 = 昨天买的衣服太宽松了，正在去换衣服的路上
- 우리 딸 육아를 도와주려고 지금 집에서 **나가는 길**throne에요 = 我现在要出去帮忙照顾我的女儿
- 옷이 젖어서 안이 다 비쳐서 새로운 옷을 사 **오는 길** Been 에요 = 我的衣服都湿了，所以我正在买新衣服回来的路上

### 이다 的过去时：

描述“길”的动词仅采用现在时。但是，您可以通过更改 이다 的时态来表达您正在路上：

- 제가 산을 내려가는 길이**었어요** = 我正要下山

> **야！ 아까 전화를 왜 안 받았어？**
> **= 嘿！你为什么不早点接电话？**
>
> 미안해~~ 내가 그때 산을 내려가는 길이었어
> = 抱歉……当时我正在下山的路上

> **내가 어제 너를 봤어！ 어디 가는 중이었어？**
> **= 我昨天看到你了！你要去哪里？**
>
> 난 어제 공부하러 학교에 가는 길이었어
> = 我正在去学校学习的路上

### 在子句之间使用 ~는 길이다：

- 목사님이 지금 교회에 오시는 길이라고 했어요 = 牧师说他现在正在去教堂的路上
- 색연필을 사러 가는 길인데 혹시 필요한 것이 있어요？ = 我要去买一些彩色铅笔，你需要什么吗？
- 제가 지금 집에 가는 길이라서 20분 후에 또 전화하면 안 돼요？ = 我现在正在回家的路上，你能在 20 分钟后给我回电话吗？

## 在往返途中：~는 길에

In addition to the usages described above, it is also common to see ~에 attached to 길 in the ~는 길 form. The meaning is: **while one is on route coming or going somewhere, he/she stopped to do something**.

- 제가 집에 가는 **길에** 빵을 사 줄까요？ = 回家的路上，我应该买点面包吗？
- 집에 오는 **길에** 맛있는 것을 사 주면 안 돼요？ = 回家路上，可以买点好吃的吗？
- 친구를 만나러 나가는 **길에** 책을 반납할 거예요 = 在出去见朋友的路上，我将归还书本
- 음식을 가져오는 **길에** 포크를 갖다 주세요 = 在你买完食物回来的路上，你能给我拿把叉子吗？

## 没有办法… ~ㄹ/을 길이 없다

길的另一种用法是在语法原则中**~ㄹ/을 길이 없다**。这字面意思是“没有方向/道路可以做......”，但更好的翻译是**“没有办法......”**

### 对于 알다（最常见）：

- 죽은 그 사람이 누구인지 **알 길이 없어요** = 无法知道死者是谁
- 우리 프로그램의 청취자가 몇 명 있는 지를 **알 길이 없어요** = 无法知道我们的程序有多少听众
- 우리가 미국에 2개월 후에 갈 거니까 그때의 환율을 **알 길이 없어요** = 两个月后我们要去美国，所以无法知道汇率

### 与其他动词搭配：

- 기후변화를 **측정할 길이 없어요** = 无法测量气候变化
- 부러진 조각상을 **고칠 길이 없어요** = 无法修复损坏的雕像
- 어제 잃어버린 통장을 **찾을 길이 없어요** = 无法找到我昨天丢失的存折
- 손전등이 없어서 빛을 **비출 길이 없어요** = 我们没有手电筒，所以我们无法照明
- 해외여행을 할 때 호객꾼을 **피할 길이 없어요** = 出国旅行时无法避免被兜售
- 낯선 사람이랑 좁은 데에서 산다면 갈등을 **피할 길이 없어요** = 如果您与不太熟悉的人住在一个狭小的空间里，就无法避免冲突
- 암에 걸린 이유는 간접흡연 때문인지 오염 때문인지 **알 길이 없어요** = 无法知道您患癌症的原因是二手烟还是污染
