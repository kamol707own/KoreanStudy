## 猜测、思考、假设，看起来像：~ㄴ가/은가/는가/나 보다

通过将 ~ㄴ가/은가/는가/나 보다 附加到句子末尾的单词，说话者表明该句子是**猜测**，并且根据证据被认为是**真实的**。

### 如何连接：

- **~ㄴ가 보다** 附加到 **이다** 和 **词干以元音结尾的形容词**
  - 여기가 휴게실**인і봐요** = 我猜这是休息室
  - 시험이 어려운가 봐요 = 我觉得考试很难

- **~은가 보다** 附加到 **词干以辅音结尾的形容词**
  - 그 사람이 싫**은і 봐요** = 我猜他不喜欢那个人

- **~는가 보다** 附加到 **所有动词** 和 **있다/없다** 的所有版本
  - 온수가 잘 안 나오**는і 봐요** = 我猜热水不太好用
  - 애기가 지금 욕조에 **있는가 봐요** = 我猜宝宝在浴缸里

- **~나 보다** 可以附加到**任何东西**（이다、形容词或动词）
  - 여기가 휴게실** Beeno 봐요** = 我猜这是休息室
  - 시험이 어렵**나 봐요** = 我觉得考试很难
  - 온수가 잘 안 나오**나 봐요** = 我猜热水不太好用

> 实际上，我几乎总是将 ~ㄴ/은가 보다 与形容词一起使用，将 이다 和 ~나 보다 与动词一起使用。

### 与 ~ㄹ/을 것 같다 的主要区别：

~ㄹ/을 것 같다 = 基于**直觉**的猜测（没有直接证据）
~ㄴ가/은가/는가/나 보다 = 基于**直接证据**的猜测

> **시험이 어려울 것 같아요** = 考试可能会很难（直觉）
> **시험이 어려운가 봐요** = 我猜考试很难（你看到学生在考试时叹气）

### 用过去时：

~나 보다 附加到 ~었~，无论动词、形容词或 이다：

- 미로가 어렵진 않았**나 봐요** = 我猜迷宫并不难
- 빨래를 아직 안 헹겼**나 봐요** = 我猜衣服还没漂完
- 누가 그 제품의 단점을 지적하지 않았**나 봐요** = 我猜没有人指出该产品的缺陷
- 경찰관이 엎드린 사람을 보고 죽은 것으로 추정했**나 봐요** = 警方似乎认为他已经死了
- 건물에 아무도 없는 것을 보니 모든 사람들이 지진에 잘 대피했**나 봐요** = 我猜他们都能够从地震中撤离
- 곰이 걷는 것이 어색해 하는 것을 보니 평생 우리에 갇혀 있었**나 봐요** = 我猜他一生都被困在笼子里
- 쓰레기가 이렇게 무더기로 쌓여 있는데 한번도 청소를 안 했**나 봐요** = 我猜他们一次也没有打扫过这个地方
- 그 사람이 오랫동안 헌신해서 어머니를 돌봐서 어머니가 거의 다 나았**나 봐** = 看起来她已经好多了
- 급하게 가다가 접시를 바닥에 엎어서 다시 요리해야 되겠**나 봐요** = 看来我得再做饭了

> “约会怎么样？”
> "음~ 괜찮았는데 남자가 조금 못생겼어 ㅠ" = 哦……还好，就是这家伙有点丑
> “아 진짜？그 건 안 돼~” = 真的吗？那可不好！

### 添加 ~네(요)：

~네(요) 通常添加到说话者学习新东西的句子中。将 ~네(요) 添加到 보다 是很常见的：

- 시험이 어려운가 보**네요** = 我觉得考试很难
- 사과가 너무 비싸나 보**네요** = 我猜苹果太贵了
- 내복을 입어야 되는가 보**네** = 我想我需要穿秋裤
- 아기가 접시를 깨뜨렸나 보**네** = 我猜宝宝打破了盘子
- 수신이 안 됐나 보**네** = 我猜没有接待处
