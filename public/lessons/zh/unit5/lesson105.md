## ~아/어지다 与 ~아/어뜨리다

在第 38 课的词汇表中，您可以找到单词 떨어지다 和 떨어뜨리다。以 ~아/어지다 结尾的单词通常是不及物词（这意味着它们不能作用于名词），具有及物动词（意味着它们可以作用于名词） ~아/어뜨리다 等价词。请注意，这不是添加到形容词的语法原则 ~아/어지다 - 例如：나쁘다 + ~아/어지다 = 나빠지다）。

以 **~아/어지다** 结尾的单词表示发生了某事 - 通常不表明是谁/什么导致了该操作的发生。例如：

- 병이 탁자에서 떨어졌다 = 瓶子从桌子上掉下来

然而，以 **~아/어뜨리다** 结尾的单词有一个实际对对象执行操作的主体（通常是人，但并非总是）。例如：

- 나는 병을 떨어뜨렸다 = 我把瓶子掉了

现在，这里有许多遵循相同模式的其他单词：

- **쓰러지다** = 折叠某些内容 / **쓰러뜨리다** = 折叠某些内容
  - 건물이 쓰러졌다 = 建筑物被推倒
  - 바람은 건물을 쓰러뜨렸다 = 风吹倒了建筑物

- **무너지다** = 折叠某些内容 / **무너뜨리다** = 折叠某些内容
  - 건물이 무너졌다 = 建筑物倒塌
  - 그 폭발은 건물을 무너뜨렸다 = 那次爆炸使建筑物倒塌

我曾经对 쓰러지다 和 무너지다 的区别感到困惑，因为它们本质上意味着相同的事情。 **쓰러지다** 用于当某物倒下时，例如树被吹倒。 **무너지다** 用于当某物自身倒塌且不会倾倒时，例如有人故意使建筑物内爆以使其自身倒塌以防止碎片撞击下一座建筑物。

- **헝클어지다** = 缠结的东西 / **헝클어뜨리다** = 缠结的东西
  - 줄이 완전히 헝클어졌어요 = 字符串完全缠结
  - 애기가 케이블을 헝클어뜨렸어요 = 婴儿缠住了电缆

- **부서지다** = 被砸碎/压碎 / **부서뜨리다** = 砸碎/压碎某物
  - 내 핸드폰이 부서졌어 = 我的手机被摔坏了
  - 나는 내 핸드폰을 부서뜨렸어 = 我摔坏了手机

- **부러지다** = 被打破/断裂 / **부러뜨리다** = 使某物断裂/断裂
  - 높은 데에서 넘어져서 뼈가 부러졌어요 = 我从高处摔下来，所以摔断了骨头
  - 제가 화가 많이 나서 연필을 부러뜨렸어요 = 我很生气，把铅笔弄断了

- **흐트러지다** = 凌乱/不整洁/分散 / **흐트러뜨리다** = 使某些东西变得混乱/散乱
  - 오랫동안 앉아 있어서 자세가 흐트러졌어요 = 我坐得太久了，姿势弄乱了
  - 친구가 제 머리를 일부러 흐트러뜨렸어요 = 我的朋友故意弄乱我的头发

- **구부러지다** = 弯曲 / **구부러뜨리다** = 弯曲某物
  - 옷걸이가 완전히 구부러져 있어요 = 衣架完全弯曲
  - 저는 옷걸이를 완전히 구부러뜨렸어요 = 我完全弯曲了衣架

- **누그러지다** = 软化/融化某人的心 / **누그러뜨리다** = 软化/融化某人的心
  - 친구의 편지를 받아서 마음이 누구러졌어요 = 收到朋友的来信，我的心都融化了
  - 친구의 편지가 제 마음을 누구러뜨렸어요 = 我朋友的信融化了我的心

- **터지다** = 爆炸 / **터뜨리다** = 爆炸某物
  - 풍선에 물을 많이 넣어서 풍선이 터졌어요 = 气球里放了太多水，气球爆炸了
  - 칼로 풍선을 터뜨렸어요 = 我用刀戳破/爆炸了气球

## ~化: 화 (化)

화 是一个汉字字符，在许多韩语单词中都表示“变化”。一些非常常见的例子是：

- 변화 = 更改
- 화장실 = 浴室/卫生间
- 화학 = 化学

在韩语中，화 通常放在 –하다 动词的名词形式之后，表示该名词代表某种变化。改变名词翻译的最常见方法是在英语单词中添加**~ification**。例如：

- 국제 = 国际/全球 → **국제화** = 国际化/全球化

If you look at the vocabulary list of this lesson, you can see that you can do this to many nouns. In addition, you can add "하다" to the words with ~화 attached to turn them into verbs. For example:

- 활성화하다 = 激活
- 일반화하다 = 概括
- 산업화하다 = 工业化
- 상업화하다 = 商业化
- 가속화하다 = 加速
- 현대화하다 = 现代化
- 합리화하다 = 合理化
- 차별화하다 = 区分
- 서구화하다 = 西化
- 다양화하다 = 多样化
- 대중화하다 = 普及
- 국제화하다 = 全球化
- 평준화하다 = 标准化
- 간소화하다 = 简化

以下是一些例句：

- 운동은 피의 순환을 **활성화**해요 = 运动促进血液流动
- 그 상황을 **일반화**하는 것은 어려워요 = 很难概括这种情况
- 산업화는 경제 성장을 **가속화**할 수 있어요 = 工业化可以加速经济发展
- 우버는 택시 서비스를 **상업화**해서 성공했어요 = Uber 成功将打车服务商业化
- 요즘에 오래된 도시를 **현대화**하는 곳 Been 많아요 = 如今有很多古老的城市正在实现现代化
- 산업화를 빨리 할수록 경제가 더 빨리 성장해요 = 工业化越快，经济发展越快
- 그 살인자가 많은 사람을 죽인 것을 자꾸 **합리화**해요 = 那个凶手不断地为他所杀的所有人合理化
- 수학 수업을 할 때 수업 내용을 **차별화**하는 것좋아요 = 当你上数学课时，区分课程内容是有好处的
- 중국 정부가 중국을 **서구화**하는 것을 반대하는 것 같아요 = 看来中国政府正在抵制中国的西化
- 새롭게 문을 연 식당은 디저트를 **다양화**해서 유명해졌어요 = 新开的餐厅因甜点多样化而受到欢迎
- 한국은 태권도를 많은 나라에서 **대중화**하려고 노력하고 있어요 = 韩国正在努力在许多国家普及跆拳道
- 요즘에 그 회사가 브랜드를 더 더욱 **국제화**하려고 하고 있다 = 该公司正在越来越多地尝试使其品牌全球化
- 한국 고등학생의 성적을 **표준화**하는 것은 학생들의 입학에 도움 Been 된다 = 韩国高中学生成绩标准化将有助于学生进入大学
- 우리 웹사이트의 목표는 한국문법을 **간소화**해서 쉽게 操作系统

## 将 이 添加到名称中

If a Korean name ends with a 받침, you will commonly see **이** added between the name and the particles ~는/은, ~이/가 and ~를/을. This is mostly related to pronunciation, and is quite colloquial.

例如，我有一个朋友，名叫희연。当我说“희영은”时，这实际上听起来更接近“희여는”，这会导致该人的实际姓名含糊不清。她的名字是희여还是희연？为了防止这种情况发生，通常会说这样一句话：

- 희영**이**는 이빨을 부러뜨렸어요

这对于所有以 받침 结尾的名称都是一样的。尽管韩语字母表中有很多字母，但您可能只会在韩语名字的最后一个音节上看到以下用作 받침 的字母：ㄱ、ㅁ、ㄴ、ㅇ、ㄹ、ㅂ。这不适用于以元音结尾的名称，因为这不会导致任何歧义。

以下是一些示例：

- 은혁** Been**가 시험준비를 하고 있어요 = 은혁 正在准备考试
- 기범**ei**는 희영**ei**를 만나러 어제 학교에 갔어요 = 기범昨天去学校见희영

在所有情况下，没有必要包含 이。如果你问韩国人有什么区别，他们会说“啊，它只是听起来‘느끼해’”。 “느끼해”通常是韩国人用来形容吃太多意大利面、面包或油腻食物时的词，尽管它也用来形容人们听到一些如此甜蜜以至于很老套的东西时的感觉。

## 将 ~아/어하다 添加到形容词

您以前可能遇到过这些词组：

- 부끄럽다 / **부끄러워하다**
- 슬프다 / **슬퍼하다**
- 기쁘다 / **기뻐하다**
- 부럽다 / **부러워하다**

这是怎么回事？这两种形式有什么区别？

这些带有 ~아/어하다 的形容词用在说话者正在谈论另一个人并试图描述他们的感受的句子中。例如：

- 그는 너무 **부끄러워했어요** = 他很害羞

如果您正在谈论另一个人，您如何知道他们的感受？你可以说她们很漂亮；你可以称他们为帅哥。这些都是基于你自己的意见。在这些情况下，如果使用的形容词描述另一个人的感受，则在形容词中添加 ~아/어하다 更为自然。

但这并不是说您永远不会看到这样的句子：

- 그는 너무 부끄러웠어요 = 他很害羞

上面这句话说出来会很奇怪，但是你也许可以在小说中找到这样的句子。在小说中，作者需要描述书中的人物，而这些人物大多数时候只是他们自己想象的虚构人物。因此，在这种情况下，不使用 ~아/어하다 是可以接受的，因为作者确切地知道对方正在引发的情绪。

正如您所知，싶다（来自 ~고 싶다）是一个形容词。它也用来表示某人想要什么。一个人很难天生就知道另一个人想要什么，因此 ~아/어하다 通常会添加到 싶다 中。例如：

- 희영이는 밥을 먹고 **싶어해** = 熙瑛想吃（米饭）

在上面的所有例子中，我都指出，当说话者不是句子的主语时，可以使用形容词+~아/어하다，并且专门与描述一个人所经历的感觉的单词一起使用。因此，这些（通常）本身就是不正确的：

- 제가 너무 부끄러워했어요
- 제가 너무 기뻐했어요
- 제가 너무 슬퍼했어요
- 제가 너무 부러워했어요

在上面的例子中，如果我把主语换成另一个人，句子就会是正确的。

但是，当说话者是句子的主语且句子中有宾语时，可以使用形容词的 ~아/어하다 形式。例如，所有这些都是正确的：

- 제가 가난을 너무 부끄러워했어요 = 我对自己的贫穷感到害羞（事实上我很穷）
- 제가 친구의 성공을 너무 기뻐했어요 = 我对我朋友的成功感到非常高兴/高兴
- 제가 친구의 죽음을 너무 슬퍼했어요 = 我对我朋友的去世感到难过
- 제가 남의 성공을 너무 부러워했어요 = 我羡慕别人的成功

## 正式主题标记 ~께서(는)

当主语是值得高度尊重的人时，助词 **~께서** 用于指示句子的主语。例如：

- 아버님**께서** 밥을 드셨습니다 = 父亲吃了
- 이 잡채는 장모님**께서** 만드신 것이에요 = 这个잡채是我婆婆做的
- 할아버지**께서** 옛날에 런던에서 사셨어요 = 我们的祖父很久以前住在伦敦
- 지금 교장선생님**께서** 잠깐 말씀을 하시겠습니다 = 现在，校长发言一下
- 우리 부장님**께서** 오늘 오후에 출발할 예정이십니다 = 我们的老板计划今天下午离开

当某人值得尊重时，可以随时这样做，但这并不是完全必要的。它在写作中以及在非常礼貌的情况下说话时更常见。在与值得尊重的人交谈时，如果不使用敬语 ~요 或 ~ㅂ/습니다 形式，很可能会让你被赶出房间；但大多数人不会关心你是否未能使用 ~께서。

It's also quite common to see "~는" added to ~께서. It could have no function at all, or it could have one of the many subtle functions that ~는 carries with it. In all cases, it totally depends on the context of the conversation. Nonetheless, all the example sentences above could have "~는" added to "께서":

- 아버님께서**는** 밥을 드셨습니다 = 父亲吃了（但其他人，也许是母亲，没有）

这就是本课的内容！
