## 过去完成时：~었~

You learned way back in Lesson 5 how to conjugate verbs adjectives and 이다 to the past tense using ~았/었다. For example:

- 제가 고등학교 때 불꽃놀이를 아주 좋아했어요 = 当我在高中的时候我非常喜欢烟花
- 어렸을 때 멸치를 아예 안 먹었어요 = 我小时候根本不吃凤尾鱼
- 사람들이 그 시장이 나쁘다고 했어요 = 人们说市长不好
- 제가 운전을 처음 배웠을 때 초보 운전자 스티커를 붙이고 운전했어요 = 当我第一次学习如何驾驶时，我开车时贴着“初学者”贴纸（在我的车上）

您可以在这些过去时态变化中附加一个额外的**~었~**，以表明该动作已经完成并且不再发生。请注意，在大多数情况下，当某事物变位为常规过去时时，可能会出现这种情况。例如，如果我们看上面的第一句话：

- 제가 고등학교 때 불꽃놀이를 아주 좋아했어요

在这句话中，说话者表明他/她喜欢烟花。仅根据句子的上下文，就可以假设说话者不再喜欢烟花。不过，这并没有具体指出，只是从句子中的情况暗示出来的。因此，从技术上讲，这个人仍然可以喜欢烟花，但从这句话中无法得知。

对于下一句话也可以这样说：

- 어렸을 때 멸치를 아예 안 먹었어요

在这句话中，说话者表明他年轻时没有吃过凤尾鱼。单从这句话来看，他现在吃凤尾鱼的可能性很大。也有可能他仍然不吃凤尾鱼。唯一给出的信息是他年轻时没有吃过它们。如果没有更多信息，我们无法对现在时做出任何假设。

在过去时变位中添加额外的 ~었~ 的目的是消除这种歧义。例如：

- 제가 고등학교 때 불꽃놀이를 아주 좋아**했었어요**

在这句话中，使用~었~表示过去的情况，不会延续到现在。在英语中，这被称为“过去完成时”，它描述过去发生的事情现在不再发生。将此简单地与“过去时”进行比较，在“过去时”中，动作是否持续到现在是不明确的。

例如：

- 어렸을 때 멸치를 아예 안 먹**었었어요** = 小时候我根本不吃凤尾鱼**（但现在我吃了）**
- 사람들이 그 시장이 나쁘다고 **했었어요** = 人们**过去**说市长很坏
- 제가 운전을 처음 배웠을 때 초보 운전자 스티커를 붙이고 운전**했었어요** = 当我第一次学习如何开车时，我带着“初学者司机”贴纸（在我的车上）开车**（但现在我不这样做了）**

~았~ 通常与 갔다 一起使用，表示某人去了某个地方并已返回。当说话者是这样的句子中的主语（去的人）时，无论你是否使用~었~，意思基本上是相同的。例如：

- 저는 붓을 사러 서울에 갔어요 = 我去首尔买画笔（根据你不在首尔的情况假设）
- 저는 붓을 사러 서울에 **갔었어요** = 我去首尔买画笔**（而且据说你已经不在首尔了）**

- 저는 연금을 받으러 캐나다에 갔어요 = 我去加拿大领取养老金（他是否还在加拿大不明确）
- 저는 연금을 받으러 캐나다에 **갔었어요** = 我去加拿大领取养老金 **（我已经不在了）**

如果说话者不是句子的主语，~었~ 的效果更明显。例如：

- 아빠가 풍경을 보러 제주에 갔어요 = 爸爸去济州岛看风景（目前还在不在含糊不清）
- 아빠가 풍경을 보러 제주에 **갔었어요** = 爸爸去济州岛看风景**（他回来了）**

将其结合成英语的一种方法是使用“had”一词。例如：

- 제가 고등학교 때 불꽃놀이를 아주 좋아**했었어요** = 当我在高中的时候我**曾经**喜欢烟花
- 어렸을 때 멸치를 아예 안 먹**었었어요** = 小时候我**没**没吃过凤尾鱼
- 제가 운전을 처음 배웠을 때 초보 운전자 스티커를 붙이고 운전**했었어요** = 当我第一次学习如何开车时，我**曾经**带着“初学者司机”贴纸（在我的车上）开车
- 사람들이 그 시장이 나쁘다고 **했었어요** = 人们**曾**说这个专业不好

下面还有更多示例：

- 오래 전에는 공룡이 실제로 존재**했었어요** = 很久以前，恐龙**曾经**曾经真正存在过
- 제가 어렸을 때 얼굴에 흉터가 **있었어요** = 当我年轻的时候，我**曾经**脸上有疤痕
- 옛날에 그 도시에는 사기꾼이 엄청 많**았었어요** = 很久以前，那个城市**曾经**有很多骗子
- 그녀가 애교가 많아서 그녀를 잠깐 좋아**했었어요** = 她很有魅力，所以我**曾经**有一点喜欢她
- 어렸을 때 등교할 때마다 이 지름길로 다니**었어요** = 小时候我每次上学都**走这条捷径
- 거기 가기 전에는 연꽃이 얼마나 예쁜지 몰**랐었어요** = 在我去那里之前我**不**知道荷花有多美丽
- 제가 옛날에 이 녹음실에서 노래를 많이 녹음**했었어요** = 我**曾经**在这个录音室录制过很多歌曲
- 그전에는 돈이 없어서 싼 질긴 고기밖에 못 먹**었었어요** = 在那之前，我们没有钱，所以我们**不能**吃除了便宜又硬的肉之外的任何东西
- 옛날에 돈이 없어서 아주 알뜰**했었지만** 지금 여유가 생겨서 풍족하게 사고 싶은 것을 사요 = 很久以前我们没有钱，所以很节俭，但现在我们有钱了，所以我们生活得很好，可以买我们想要的东西

这就是本课的内容！
