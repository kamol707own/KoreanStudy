## 缩写或省略助词：난、건、걸 等……

在第 101 课中，您可能已经了解本课中介绍的大部分内容。但是，如果您一直在韩国境外学习韩语（因此无法经常见到韩国人），那么这些概念对您来说可能是新的。

It is common to abbreviate the particles ~는 or ~를 by attaching just ~ㄴ or ~ㄹ to a noun. Naturally, the noun must end in a vowel. For example:

- 나를 可以缩写为 날
- 너를 可以缩写为 널
- 나는 可以缩写为 난
- 너는 可以缩写为 넌

可以将 저는 缩写为 전，但这样做通常被视为非正式的 - 这有时意味着这是不合适的。

这些类型的缩写经常出现在演讲中。然而，说话者通常甚至没有有意识地缩写这些单词。相反，他们的发音“나를”（例如）可能听起来更接近句子中的“날”。您最常看到这些缩写的地方是互联网消息传递中，例如 Facebook 或 Kakao（韩国消息传递应用程序）。也可以在使用直接引用的文献中看到这些内容。在这些情况下，作者经常尝试以模仿真实句子的声音的方式进行写作，就像说话一样。

以下是一些示例：

- **난** 어렸을 때 해병이었어 = 当我年轻的时候，我是一名海军陆战队员
- **넌** 누구를 기다리고 있니？ = 你在等谁？
- **난** 천둥이 치는 소리를 들었어 = 我听到雷声
- 아버지는 **날** 위해 튀김을 사 주었어 = 爸爸给我买了一些油炸食品

从技术上讲，这种缩写可以用于任何以元音结尾的名词。虽然这最常使用 나 和 너 来完成，但使用“것”也很常见。

首先请记住，“것”可以缩写为“거”，含义没有区别。例如：

- 저는 신선한 **것을** 먹고 싶어요 = 我想吃点新鲜的东西
- 저는 신선한 **거를** 먹고 싶어요 = 我想吃点新鲜的东西
- 저는 내일 각종의 만두를 먹을 **거예요** = 我明天要吃各种饺子
- 저는 내일 각종의 만두를 먹을 **것이에요** = 我明天要吃各种饺子

~를 或 ~는 可以缩写为直接附加到“거”，就像 너 或 나 一样：

- 거 + 를 = **걸**
- 거 + 는 = **건**

例如：

- **이건** 얼마예요？ = 这个多少钱？
- **그걸** 하지 마세요 = 请不要这样做！
- 저는 신선한 **걸** 먹고 싶어요 = 我想吃点新鲜的东西

正如我所说，从技术上讲，这个缩写规则可以适用于任何以元音结尾的单词。虽然您会在韩语中经常看到（并听到）난/넌/날/널/걸/건，但您会发现这种情况在其他名词中很少出现。您会发现这些结构最常见的地方是短信或其他形式的互联网消息传递。例如：

- 나의 침대는 너무 딱딱해！ = 我的床太硬了！
- 여긴 금연 구역이라 여기서 담배를 피우지 마세요 = 这里是非吸烟区，所以请不要在这里吸烟

完全省略这些助词也是很常见的。同样，这样做在试图模仿演讲的演讲或写作形式中最常见（例如故事或互联网消息中的直接引用）。例如：

而不是说：
- 나는 밥을 먹고 싶어 = 我想吃（米饭）

通常简单地说：
- **나 밥 먹고 싶어** = 我想吃（米饭）

它基于这样的想法：在韩语中，如果可以假设某件事，那么你实际上不需要说出来。也就是说，如果你可以假设助词存在，那么就没有必要说它们。例如：

- **나 이 손목시계 늘 차고 있어** = 我总是戴着手表
- **나 만두 먹기 싫어** = 我不想吃饺子

虽然我们讨论的是短信和互联网消息传递的主题，但我想向您介绍其他形式的“互联网”语音。

## 互联网语音（ㅋㅋ、ㅠㅠ、넘、ㅇ）

如果您曾经与韩国人（尤其是 25 岁以下的人，尤其是女性）进行过文本对话，您会发现语法和单词结构可能与您习惯的非常不同。以下内容在韩语短信和消息中非常常见：

- **ㅋㅋ** = 无论您在消息中包含多少个这些内容，其含义都类似于英语中的“lol”。这是因为“ㅋㅋㅋㅋㅋ”的发音听起来像是有人在咯咯地笑。通常，ㅋ 字符越多，您笑得越多。这不太常见地表示为“ㅎㅎ…”。
- **ㅠㅠ** = 与上面类似，消息中包含多少个并不重要 - 尽管通常有两个。这些字母代表两只流着泪水的眼睛——表明你很悲伤。有些人输入两个以上以强调他们非常悲伤。这不太常见地表示为“ㅜㅜ”。
- **넘** = 这是너무 的缩写。它可以放在句子中，就像“너무”一样，有些人经常包含多个，好像是为了强调“非常非常……”例如：
  - 난 **넘넘** 배고파！ = 我好饿啊！
- **^^** = 这代表一张幸福的脸。韩国人微笑时，眼睛通常呈半月形，这就是每个“^”符号所代表的意思。
- **낼** = 这是내일 的缩写。
- **꺼** = 这是것 或거 的缩写。许多人将“거”发音为“꺼”。您最常看到“꺼”的地方是在单词“내”后面作为“내 꺼”（我的东西/我的）。例如：
  - 넌 **내꺼**야！ =你是我的了！
  - 그게 **내꺼**！ = 那是我的！
- **ㅅ instead of ㅆ** = For no real reason, people on the internet will often substitute ㅅ for ㅆ when it is used as the bottom of a syllable. For example, instead of "있어" they will write "잇어"
- **无空格** = 韩国人在互联网上写短信或发帖时，单词之间没有空格也很常见。例如：응너혼자잘다녀와

## 그러니까

这个词不一定是网络言论或俚语，但它在一般言论中很常见。使用“그러니까”的最佳方式是单独使用（或在子句之前，但与子句分开），在某人提及某些事实（通常是他们对某事的看法）之后使用。通过说“그러니까”，最好的英语翻译是“That's the thing！”或“我知道对吧？！”

例如：

> 第一个人：아~ 김연아가 올림픽 금메달을 못 따는 걸 믿을 수 없어ㅠㅠ
> = 啊…我不敢相信김연아没有在奥运会上赢得金牌
>
> 第二个人：나도！ 그 러시아에서 온 선수가 많이 넘어졌는데 어떻게 이길 수 있어？
> = 我也是！那位来自俄罗斯的滑冰选手摔倒了这么多次，她怎么能赢呢？
>
> 第一个人：**그러니까！** = 就是这样！

“그러니까”不一定是单独的。有时后面会跟另一个子句。

- **그러니까！** 김연아가 러시아 선수보다 훨씬 잘했어~
= 就是这样！ 김연아 比俄罗斯选手做得好得多！

当与实际子句连接使用时（而不仅仅是单独使用），您可以将其视为 그렇다 + ~(으)니까 的含义。将这两个放在一起，你会得到 그러니까 ，它类似于“그래서”，意思是“这就是为什么/这就是为什么......”。例如：

- **그러니까** 에너지를 절약해야지！
= 这就是为什么我们需要节约能源！
- **그러니까** 그것을 만지기 싫어。 너무 징그러워서
= 这就是为什么我不想碰它。太恶心了
- **그러니까** 학생들이 반의 목표를 위해 각자의 역할을 잘 해야 돼요
= 这就是为什么班级里的每个学生都需要做好自己的角色才能实现班级目标

## 그치

“그치”这个词经常用在一个人发表声明之后，并要求听者同意他/她所说的内容。实际上，这与第 93 课中介绍的结尾 ~지/죠 非常相似，因为它实际上是“그렇지”的缩写。

例如：

- 날씨가 너무 덥지？ = 天气很热吧？ （不是吗？）
- 날씨가 너무 더워，**그치？** = 天气很热，不是吗！？
- 우리가 어제 산 토마토가 엄청 신선하지=我们昨天买的西红柿很新鲜吧？
- 우리가 어제 산 토마토가 엄청 신선해, **그치?** = 我们昨天买的西红柿很新鲜吧！？

그치 的正式等价物是 **그쵸**（그렇죠 的缩写）。例如：

- 어젯밤에 안개가 많이 꼈죠？ = 昨晚有很大的雾，是吗？
- 어젯밤에 안개가 많이 꼈어요，**그쵸？** = 昨晚雾很大，不是吗？

当听众想要表示同意刚才所说的内容时，**그치/그쵸**也可以单独使用。这种用法与 그러니까 的含义非常相似（当它也单独使用时）。例如：

- 한국피자가 제일 맛있다！ = 韩国披萨是最好吃的披萨！
- **그치！** =（我同意！）
- **그러니까！** =（就是这样！）

请注意，使用 그치 和 그쵸 几乎专门用于说话。您唯一一次看到它们是通过某种消息传递系统编写的，其中书面对话试图模仿实际对话。

## 아이 的缩写

아이 用于指代婴儿。它通常缩写为**애**。作为成年人，通常将儿童（大约 12 岁及以下）称为 애。

**얘、걔和쟤**分别是이 아이、그 아이和저 아이的缩写。

例如：

- **쟤**怎么办？ = 那是谁？
- **쟤**і 우리 선생님의 딸야 = 那（人）是我们老师的女儿
- **얘**і 내і 전에 말한 친구야 = 这就是我说的朋友
- **걔**і 코로나에 걸린 사람과 접촉해서 **걔**도 걸렸어요 = 那孩子是新冠病毒感染者的密切接触者，所以他也感染了新冠病毒

## ㅇ 结束

用韩语（说话或写作时）可以做的最可爱的事情之一就是将 **~ㅇ** 作为 받침 添加到没有单词的单词中。年轻的韩国女孩在口语和写作中都会一直使用这种形式。当老年人（年龄超过 30 岁左右）这样做时，他们很可能是在开玩笑。

这通常不会直接添加到名词上，而是更常见地在动词或形容词变形后附加。例如：

- 먹었어 ~ **먹었엉**
- 배고파 ~ **배고팡**

一些例子：

- 난 다 **왔엉**！ = 我来了！
- 내일 안 갈 **거양** = 我明天不去

~ㅇ 也可以添加在 요 或 ~습니다 之后，以可爱的方式结合礼貌的结尾。例如：

- 내일 맛있는 걸 사 **줘용**！ =明天给我买点好吃的吧！
- **감사합니당**！ = 谢谢！

~ㅇ 所附加的最常见的非活用词是“네”（是）。说 **"넹"** 是表示“是”的一种可爱方式。
