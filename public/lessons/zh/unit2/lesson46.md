## 语法点

### 必须：~아/어야 하다

将 **~아/어야 하다** 添加到词干，表示“one has to”或“one Must”：

- 공부하다 → 공부해야 한다 = 必须学习
- 먹다 → 먹어야 한다 = 必须吃饭
- 가다 → 가야 한다 = 必须走

**示例：**

- 저는 밥을 먹어야 해요 = 我要吃饭
- 저는 지금 공부해야 해요 = 我现在必须学习
- 저는 집에 가야 해요 = 我得回家了
- 친구를 만나러 지금 가야 해요 = 我现在得去见我的朋友
- 제 말에 동의해야 해요 = 你需要同意我所说的
- 대학교에 가고 싶다면 열심히 공부해야 해요=如果你想上大学，你就必须努力学习

> **注意：** 在韩语中，~아/어야 하다 涵盖“必须/必须”和“应该”——这种区别不像英语那么严格。

### ~아/어야 되다

将 하다 替换为 되다 以获得相同的含义（在语音中更常见）：

- 우리는 빨리 가야 돼 = 我们必须走快点
- 울타리를 넘어야 돼요 = 我们需要越过栅栏
- 시력이 안 좋아서 안경을 써야 돼요 = 我的视力不好所以我必须戴眼镜
- 성공하고 싶으면 매일 열심히 해야 돼요 = 如果你想成功，你需要每天努力工作

### ~아/어야 지/죠

使用 ~지 或 ~죠 代替 하다/되다 （主要是会话式的）：

- 우리 빨리 가야지！ = 我们必须走快点！
- 먹어야지！ =你必须吃饭！
- 운명을 믿어야지 = 你需要相信命运

> ~아/어야 和 지/죠 之间没有空格。

### 过去时和将来时

**过去（必须）：**

- 그때 열심히 일해야 되었어요 = 那时我必须非常努力地工作
- 복사기를 수리해야 되었어요 = 我们必须修理复印机
- 시력이 워낙 안 좋아서 화면에 가까이 있어야 되었어요 = 我的视力不好，所以我必须靠近屏幕

**未来（必须）：**

- 10분 후에 가야 될 거예요 = 我们必须在 10 分钟后出发
- 그 이를 뽑아야 될 것 같아요 = 我们可能需要拔掉那颗牙齿
- 신입생들을 위해 선물을 준비해야 할 거예요=我们要为新生准备一份礼物

### ~아/어야겠다

附加 ~겠다 来表达“我更好......”或“我想我更好......”（基于新信息）：

- 나는 지금 가야겠다 = 我最好现在就出发
- 남자친구랑 내일 헤어져야겠다 = 明天我就要和男朋友分手了
- 그녀를 위해 선물을 사야겠어요 = 我得给她买件礼物

### 需要：필요하다

**필요하다** 表示“需要”（被视为形容词，而不是动词）：

- 使用 **~이/가** （不是 ~을/를）与所需名词
- 나나 밥이 필요하다 = 我需要食物/米饭
- 나는 여자 친구가 필요하다 = 我需要一个女朋友
- 우리 회사는 새로운 복사기가 필요해요 = 我们的办公室需要一台新复印机

### 需要：~ㄹ/을 필요가 있다/없다

使用动词描述的名词 **필요**（“必要性”）来表示“我需要……”：

- 밥을 먹을 필요 = 吃饭的必要性 → 밥을 먹을 필요가 있다 = 我需要吃饭

**我需要：**

- 저는 그 여자랑 결혼할 필요가 있어요 = 我需要娶那个女孩
- 시험공부를 곧 할 필요가 있어요 = 我需要尽快学习
- 강한 캐릭터를 만들 필요가 있어요 = 我们需要塑造一个坚强的角色
- 예외를 다 설명할 필요가 있어요 = 您需要解释所有例外情况

**我不需要：**

- 제자리에 놓을 필요가 없어요 = 您无需将其放回原处
- 그렇게 가까이 앉을 필요가 없어요 = 没必要坐那么近
- 그렇게 할 필요가 없어요 = 你不需要那样做
