## 语法要点

### 1. 一项不确定条款：~는지

在从句末尾添加 **~는지**，以表示不确定性、猜测或句子中嵌套的疑问。

**结构：** [不确定从句] + ~는지 + [如 的主要动词모르다]

>  **저는 친구가 어디 가는지 모르겠어요**= 我不知道我的朋友要去哪里

**何时使用：** 如果从句中包含疑问词（누구, 뭐, 언제, 어디, 왜, 等），则会自动使用 ~는지：

- **엄마가 누구랑 먹는지 모르겠어요** = 我不知道妈妈和谁一起吃饭
- **엄마가 뭐 먹는지 모르겠어요** = 我不知道妈妈在吃什么
- **엄마가 왜 먹는지 모르겠어요** = 我不知道妈妈为什么在吃东西

**如果没有疑问词**，~는지 意为“如果”：

- **엄마가 지금 먹고 있는지 모르겠어요** = 我不知道妈妈现在是不是在吃饭

> **注：**  通常出于礼貌모르다会被替换为  **모르겠어요**( 모르겠다)。此处它不表示将来时。

### 2. 过去时：~았/었는지

Add ~았/었 before ~는지 for past uncertain clauses:

- **엄마가 왜 먹었는지 모르겠어요** = 我不知道妈妈为什么吃那个
- **열쇠를 어디 두었는지 잊어버렸어요** = 我忘了把钥匙放哪儿了

> **口语中的韩语：** 口语中通常用 ~ㄴ/은지 代替 ~았/었는지。这两种说法听起来都很自然。

### 3. 将来时：~ㄹ/을지

Add ~ㄹ/을 before 지 for future uncertain clauses:

- **택배가 언제 올지 모르겠어요** = 我不知道什么时候会送达
- **오후에 비가 올지 모르겠어요** = 下午可能会下雨

> 当没有疑问词时，“~ㄹ/을지 모르다”通常译为 **“可能……”**

### 4. ~는지 与形容词

对于形容词从句，请使用 **~ㄴ/은지** 代替 ~는지：

- **제가 준 것이 괜찮은지 모르겠어요** = 我不知道我给的东西行不行
- **이 빛이 충분히 밝은지 모르겠어요** = 我不知道这盏灯够亮吗
- **내일 날씨가 쌀쌀할지 모르겠어요** = 我不知道明天的天气会不会有点冷

### 5. “如果……或者不……”

使用两个带有“~는지”的从句来表达“是否”：

- **내일 영화를 볼지 안 볼지 모르겠어요** = 我不知道明天会不会去看电影
- **수술을 받을지 안 받을지 확실하지 않아요** = 目前还不确定我是否会做手术

**不同的结果（不仅限于正/负）：**

- **내일 공원에 갈지 영화를 볼지 모르겠어요** = 我不知道是去公园还是去看电影

> **提示：** 对于动词하다，应将从句简化：  （공부했는지**안 했는지**而不是 안 공부했는지）

### 6. 将 ~도 连接到 ~지

**~ㄹ/을지도 모르다** 是一种常见的用法。符号 ~도 带有“可能或不可能”的微妙含义，但在实际应用中，它与 ~ㄹ/을지 모르다 基本上是相同的：

- **내일 비가 올지도 모르겠어요** = 明天可能会下雨
- **내일 비가 올지 모르겠어요** = 明天可能会下雨

> **用法：** ~도 仅用于未来时的不确定从句中。它不与疑问词搭配使用。

### 7. 问“你会……吗？”

使用 ~지 알아요 来询问别人是否知道如何做某事：

- **서울에 어떻게 가는지 알아요?** = 你知道怎么去首尔吗？
- **그 단어를 어떻게 발음하는지 알아요?** = 你知道这个词怎么读吗？

## 例句

- **택배가 언제 올지 모르겠어요** = 我不知道什么时候会送货
- **택배로 보내야겠어요** = 我得通过快递寄出去
- **가격을 확인해보자** = 来看看价格吧
- **용돈을 얼마나 줘야 할지 모르겠어요** = 我不知道该给多少零花钱
- **제가 구한 아르바이트가 좋은지 모르겠어요** = 我不知道我找到的这份工作怎么样
- **비상출입구가 어디 있는지 찾았어요** = 我们找到了紧急出口的位置
- **정부가 왜 예산을 줄이는지 모르겠어요** = 我不知道政府为什么要削减预算
- **그 셔츠를 언제 버렸는지 기억이 안 나요** = 我不记得是什么时候把那件衬衫扔掉的
- **열쇠를 어디 두었는지 잊어버렸어요** = 我忘了把钥匙放哪儿了
- **이 빛이 충분히 밝은지 모르겠어요** = 我不知道这盏灯够亮不够
- **이 독을 마시면 치료할 수 없어요** = 如果你喝了这种毒药，就无法治愈
- **저는 시인이 되려고 노력하고 있어요** = 我正在努力成为一名诗人
