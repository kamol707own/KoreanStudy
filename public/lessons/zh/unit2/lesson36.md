## 第36课：表示“像……一样”：  보이다/ ~아/어 보이다

### 关键语法要点

#### 보이다 — 被看见 / 看见
（**보다**看见）的被动形式。用于表示某物能/不能被看见。

| 韩语 | 英语 |
|--------|---------|
|   |저는 소방서가**보여요** 我能看到消防站 |
| 电视가  **안 보여**| 我看不到电视 |
|   |가격표가**안 보여요** 我看不清价格标签 |

> **注：** 韩语中使用了不及物动词（보이다），但英语将其译为及物动词（“我看不见”）。字面意思是：“电视看不见。”

---

#### ~  같이 보이다— 像（名词）一样
放在名词和谓语**같이**之后，并用冒号分隔**보이다**：

| 韩语 | 英语 |
|--------|---------|
|   |너는 원숭이**같이 보여** 你长得像只猴子 |
|  저의 남자친구는 교수님**같이 보여요** | 我男朋友长得像那位教授 |
|   |너는 고등학생**같이 보여** 你看起来像个高中生 |

**关于 ~는 것：**
-   =네가 새로운 집으로 이사하고 싶은 것**같이 보여** 看来你想移动

---

#### 名词 + 맛/냄새 같다 — 味道/气味像……

| 韩语 | 英语 |
|--------|---------|
|   |김치**맛 같아** 味道像泡菜 |
|   |삼겹살은 베이컨**맛 같아요**  尝삼겹살起来像培根 |
|   |김치 찌개**냄새 같아** 闻起来像泡菜汤 |

---

#### ~아/어 보이다 — 描述外观（形容词）
在形容词后加上 ~아/어 并接 **보aida**，即可表示某人/某物看起来[形容词]：

| 韩语 | 英语 |
|--------|---------|
|  ?왜 그렇게**행복해 보여요** | 你为什么看起来这么开心？ |
|   |그 남자 종아리가 아주**강해 보여요** 那个男人的小腿看起来很结实 |
|   |무릎이**아파 보여요** 你的膝盖看起来有点疼 |
|  소방 훈련이**힘들어 보여요** | 消防训练看起来很难 |
|   |화장이**예뻐 보여요** 你的妆容很漂亮 |
|   |그 남자가**의욕이 많아 보여요** 那人看起来很有干劲 |

---

#### 들리다 — 被听到
（**듣다**听到）的被动形式：

| 韩语 | 英语 |
|--------|---------|
|  소리가**안 들려요** | 我什么都听不到 |
|   |목소리가**잘 들려** 我听得很清楚 |
|  뭔가 터지는 소리가**들렸어요** | 我听到一声爆炸声 |
