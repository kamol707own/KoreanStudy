## 语法点

### 用法 1：当/如果一个动作发生，另一动作就会发生

将 **~(으)면** 添加到动词或形容词的词干以创建“when”或“if”。第二个子句是对第一个子句发生时会发生什么的假设。

**示例：**

- 집에 도착하면 빨래를 할 거예요 = 当我到家时，我会洗衣服
- 신호를 보면 저에게 말을 바로 해 주세요 = 当/如果您看到信号，请立即告诉我
- 과학자가 되면 피부에 습도의 영향을 연구하고 싶어요 = 当/如果我成为一名科学家，我想研究湿度对皮肤的影响
- 내일 비바람이 오면 경기가 취소될 거예요 = 如果明天有暴风雨，比赛将被取消

> 如果第一个事件是确定的→“何时”。如果不确定→“如果”。

**Past tense (would have):** Add **~았/었** before **~으면**:

- 내가 공부했으면 시험을 합격했을 것이다 = 如果我学习，我就会通过测试
- 내가 밥을 먹었으면 배고프지 않았을 것이다 = 如果我吃东西，我就不会饿了
- 햇살이 그렇게 강하지 않았으면 밖에 나갔을 거예요 = 如果阳光不是那么强烈，我就会出去了

### 用法 2：一般因果关系

表示当一个动作发生时，通常会发生另一个动作（常识）：

- 비가 오면 날씨가 추워져요 = 下雨时，天气会变冷
- 잠을 못 자면 다음 날에 몸이 피곤해져요 = 当你睡不好的时候，第二天你就会很累
- 장거리 운전을 하면 엉덩이가 아파요 = 当你长途驾驶时，你的屁股会酸痛
- 콜라를 매일 마시면 건강이 나빠져요 = 当你每天喝可乐时，你的健康状况会恶化

### 用法3：每当（重复动作）

每次第一个子句出现时，第二个子句就会出现：

- 피자를 먹으면 저는 콜라를 마셔요 = 每当我吃披萨时，我都会喝可乐
- 아버지가 운전하면 습관으로 담배를 피워요 = 每当我爸爸开车时，他都会抽烟
- 내가 공부를 하면 엄마는电视를 끈다=每当我学习时，妈妈就会关掉电视

### ~ㄴ/는다면

在 **~면** 之前使用普通/日记形式结合动词。这强调了该子句是一个假设：

|紧张|示例|
|-------|---------|
|现在时动词| 가다 → 간다면, 먹다 → 먹는다면 |
|现在形容词| 행복하다 → 행복하다면 |
|过去式动词| 가다 → 갔다면, 먹다 → 먹었다면 |
|过去形容词| 행복하다 → 행복했다면 |
| 이다 | 이라면 / 이었다면 |
| 아니다 | 아니라면 / 아니었다면 |

### 만약

当结果不确定时在句子中使用的副词。与 ~(으)면 常见：

- 만약 내가 공부했으면 시험을 합격했을 것이다 = 如果我学习，我就会通过测试
- 만약 내일 비바람이 오면 경기가 취소될 거예요 = 如果明天有暴风雨，比赛将被取消

### 그러면/그렇다면

通过将 ~(으)면 或 ~ㄴ/는다면 添加到 그렇다 中，您将得到“if so”：

> 第一个人：내일 비가 올 것 같아요 = 明天可能会下雨
> 第二个人：그러면/그렇다면 공원에 안 갈 거예요 = 如果是这样，我不会去公园

### 아니면：“如果不是”/“或”

通过将 아니다 与 ~면 组合，您可以得到“如果不是”/“或”：

- 저는 밥을 먹고 싶어요. 아니면 죽을 것 같아요 = I want to eat rice. If not, I will probably die
- 저는 밥 아니면 사과를 먹고 싶어요 = 我想吃米饭或苹果
