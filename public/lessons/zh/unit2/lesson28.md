## 语法点

### 1. 不规则~는 것（现在时）

唯一影响现在时 ~는 것 的不规则是 **ㄹ 不规则**。当词干以ㄹ结尾时，ㄹ被移除，直接添加~는。

> **示例：** 열다 → **여는 것**（开头）

|不规则 |词| + ~는 것 |
|-----------|------|----------|
| ㅅ | 짓다 | 짓는 것 |
| ㄷ | 걷다 | 걷는 것 |
| ㅂ | 돕다 | 돕는 것 |
| ㅡ | 잠그다 | 잠그는 것 |
| 르 | 부르다 | 부르는 것 |
| ㄹ | 열다 | **여는 것** |

### 2. 过去时 (~ㄴ/은 것)

正方形、ㄷ、ㅂ 和 ㄹ 不规则图形都会发生变化：

|不规则 |动词| + ~ㄴ/은 것 |
|-----------|------|-------------|
| ㅅ | 짓다 | 지은 것 |
| ㄷ | 걷다 | 걸은 것 |
| ㅂ | 돕다 | 도운 것 |
| ㅡ | 잠그다 | 잠근 것 |
| 르 | 부르다 | 부른 것 |
| ㄹ | 열다 | 연 것 |

### 3.将来时 (~ㄹ/을 것)

与过去时相同的不规则形式，使用 ~ㄹ/을 代替：

|不规则 |动词| + ~ㄹ/을 것 |
|-----------|------|-------------|
| ㅅ | 짓다 | 지을 것 |
| ㄷ | 걷다 | 걸을 것 |
| ㅂ | 돕다 | 도울 것 |
| ㄹ | 열다 | 열 것 |

### 4.“我最喜欢的事”：가장 좋아하는 것

韩语里没有“最喜欢”这个词。使用 **가장 좋아하는 것** （“我最喜欢的东西”）：

- **내가 가장 좋아하는 것** = 我最喜欢的东西
- **제가 가장 좋아하는 음식은 김치예요** = 我最喜欢的食物是泡菜
- 使用 **~에 있어서** 表示“我最喜欢 X 的事情”：
  - **한국에 있어서 내가 가장 좋아하는 것은 한식이야** = 关于韩国我最喜欢的是韩国菜

### 5. ~는 与 싶다、있다 和 없다

当用 싶다、있다 或 없다 描述名词时，请使用 **~는** （而不是 ~ㄴ/은）：

- **내가 만나고 싶은 사람** = 我想见的人
- **펜이 있는 사람** = 有笔的人（不是 있은）
- **펜이 없는 사람** = 没有笔的人

> **注意：** 재미있는、맛있는、관심이 있는 都使用 ~는，因为它们派生自 있다。

### 6. Using 그 in ~는 것 sentences

指示词 (이/그/저/나의) **紧接在名词之前**，而不是在动词从句之前：

- ✅ **내가 만난 그 사람** = 我遇到的那个人
- ❌ 그 내가 만난 사람

## 例句

- **어른들이 이런 영화를 보통 좋아하지 않아요** = 成年人通常不喜欢这类电影
- **그 문제가 우리 일에 무슨 영향을 미칠 거예요?** = 这个问题会对我们的工作产生什么影响？
- **저는 친구가 문을 여는 것을 봤어요** = 我看到我的朋友打开门
- **제가 가장 좋아하는 것은 영화를 보는 것이다** = 我最喜欢的事情是看电影
- **솔직히 제가 어떻게 할지 몰라요** = 老实说，我不知道我会做什么
- **지하철을 놓쳤기 때문에 택시를 타야 돼요** = 我错过了地铁，所以我必须乘坐出租车
- **버스가 출발했을 때 사람들은 움직였어요** = 当巴士出发时，人们开始移动
