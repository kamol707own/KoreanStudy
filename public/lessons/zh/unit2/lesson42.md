## 语法要点

### 的简单用法 때

这个词的意思**때**是“时间”。它可以放在某个事件或时段之后，用来指代该事件发生期间的时间：

- 저녁 때 = 晚餐/晚上时分
- 방학 때 = 学校放假期间
- 회의 때 = 会议期间
- 고등학교 때 = 高中时期
- 대학교 때 = 大学期间

> 示例： 저는 방학 때 집안에서 공부를 할 거예요= 假期里我打算在家里学习

### 时间：…… ~ㄹ/을 때

**때** 可与**~는 것**原则**结合使用，以指明某件事发生的具体时刻。将来时形式**~ㄹ/을**通常用于描述때：

>  =**내가 밥을 먹을 때** “我吃饭的时候” → “当我吃饭时”

- 通常表示一般时间或将来时间
- 当两个分句的主语相同时，不要重复写主语

**示例：**

- 저는 돈을 받을 때 행복할 거예요 = 收到钱后，我会很高兴的Simplified Chinese (Mainland)
- 뼈마디가 아플 때 이 약을 드세요 = 关节疼痛时，请服用此药
- 머리를 감을 때 비누로 해요 = 我洗头的时候，会用肥皂洗
- 오랫동안 공부할 때 뇌가 아파요 = 学习时间一长，我的脑袋就疼
- 대통령을 만날 때 저는 아주 예의가 바를 거예요 = 当我见到总统时，我会非常有礼貌

> **重要提示：** 主要动作恰好发生在~ㄹ/을 때子句所指明的时刻——而不是在该时刻之后。当与  或가다  搭配使用时오다，动作发生在前往/返回的过程中，而不是到达之后。

### 过去时：~았/었을 때

要表示某事发生在过去，请在 **~았/었** 前面添加 **~ㄹ/을 때**：

- 먹었을 때 = 当我吃饭的时候
- 갔을 때 = 当我去了……
- 공부했을 때 = 我上学的时候

**示例：**

- 엄마가 갔을 때 저는 울었어요 = 妈妈走后，我哭了
- 제가 어렸을 때 곤충을 먹었어요 = 我小时候经常吃虫子
- 그 연예인의 사인을 받았을 때 너무 설레었어요 = 当我得到那位明星的签名时，我真的非常兴奋

### 具有 때

可以在  后添加助词 **~에**（때但通常省略）。当  充当때主语/宾语时，还可以附加其他助词：

- 우리가 지난 번에 만났을 때가 아주 재미있었어요 = 我们上次见面真的很有趣
- 저는 사막에서 살았을 때를 잊어버리고 싶어요 = 我想忘掉曾在沙漠里生活的那段时光
- 키가 클 때까지 얕은 수영장에서만 수영할 거예요 = 在我长高之前，我只会去浅水池游泳
- 저는 그 팀을 어렸을 때부터 응원했어요 = 我从小就一直为那支球队加油
- 내가 한국에 있을 때마다 한국어로 말하고 싶어 = 每次去韩国，我都想说韩语

### “有时……”的用法

때 可以表示某种“时间”或“情况”已经发生，通常与 있다/없다 连用：

- 그 친구를 죽이고 싶을 때가 있어요 = 有时候真想掐死那个朋友
- 밤 늦게 배고플 때가 많아요 = 很多时候，我晚上会感到饿
