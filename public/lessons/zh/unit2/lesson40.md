## 关键语法要点

### 命令式

韩语中有多种下达命令的方式，从最不正式到最正式依次为：

### 动词词干 + ~아/어(요)

下达指令最简单、最不正式的方式：

- 밥을 천천히 먹어 = 慢慢吃
- 열심히 공부해! = 努力学习！
- 添加 **~요** 以示礼貌：  밥을 천천히 먹어요= 慢慢吃吧

### 动词词干 + ~(으)세요

最常见的正式命令式形式（等同于 ~(으)셔요）：

- 이것을 보세요 = 看看这个
- 빨리 올라오세요 = 快上来
- 수고하세요! = 加油！（离开公司时常见的问候语）
- **안녕히 계세요** = 再见（安息吧）

### 动词词干 + ~아/어라

年长者（父母/祖父母）在向年轻人下达指令时使用：

- 빨리 가라! = 快点！
- 내 말을 들어라 = 听我说

> **注：** 这种表达方式在正式程度上与 ~아/어 类似，但听起来更具权威性。

### 动词词干 + ~(으)십시오

非常正式的命令语气，用于对应当受到极高尊重的人说话时：

- 여기서 내리십시오 = 在这里下车（在首尔地铁里听到的）

### 否定命令式：~지 말다

告诉某人不要做某事：

- 가지 마! = 别走！
- 가지 마세요! = 别走！（礼貌语）
- 집에 가지 마! = 别回家！
- 권력을 남용하지 마세요 = 不要滥用权力/职权

> **注：**  在命令式变位中말다属于不规则动词： 가지 말아, 가지 마라, 가지 마요, 가지 마세요, 가지 마십시오

### ~지 말고

将一个否定指令与一个肯定指令结合起来（不要做X，而要做Y）：

- 매일 같은 운동을 하지 말고 많이 쉬세요 = 不要每天做同样的锻炼，要保证充足的休息

### 指路

- 오른 쪽으로 가세요 = 向右走
- 왼 쪽으로 가세요 = 向左走
- 직진하세요 = 直行
- 건물을 지나가서 오른 쪽으로 가세요 = 经过那栋楼后，向右走

### 带 ~아/어 보다 的命令式语气

添加 ~아/어 보다 以表示“尝试执行某操作”：

- 이것을 먹어 봐! = 试试这个吧！（或者简称为“吃这个吧！”）
- 여기 와 보세요 = 过来（试着过来））
- 문을 열어 봐 = 打开门（试着打开门）

## 例句

- 부끄러워하지 마세요 = 别害羞
- 오늘도 수고한 자신에게 "잘했다!"라고 칭찬해주세요 = 今天也要对自己说一句“干得不错！”，好好表扬一下自己。
- 건물을 지나가서 오른 쪽으로 가지 말고 계속 직진하세요 = 经过那栋楼后，不要右转，而是继续直走
- 이 제품 수준을 높여 보세요 = 努力提升该产品的水平/标准
- 여기서 내리십시오 = 在这里下车
