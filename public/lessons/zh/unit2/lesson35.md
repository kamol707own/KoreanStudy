## 第35课：似乎是／可能是： 것 같다

### 关键语法要点

#### ~ㄹ/을 것 같다 — 似乎会…… / 可能……
与将来时 ~ㄹ/을 것 结合使用，같다用于表达可能性或猜测。

**将来时（对将来事情的猜测）：**
-   =비가**올 것 같아** 可能要下雨了
-  저는 친구들이랑 내일 낚시를**할 것 같아요** = 明天我可能要和朋友去钓鱼
-   =새우가 너무 비쌀**것 같아요** 这些虾可能太贵了

**现在时 ~는 것 같다（根据现有证据来看）：**
-   =엄마는 기다리고 있는**것 같아요** 看来妈妈在等着
-  그는 휴식을 하는**것 같아요** = 看来他现在正在休息

**过去时 ~ㄴ/은 것 같다（似乎……，根据证据）：**
-   =부장님이 그 일을 이미 다 한**것 같아요** 看来老板已经把所有工作都做完了
-   =옆 집에서 사는 사람은 그 소나무를 자른**것 같아요** 看来是邻居砍了那棵松树

**过去时 ~았/었을 것 같다（纯属猜测，无证据）：**
-  아빠가 돈을 이미 냈을**것 같아요** = 爸爸可能已经付了（但我没看到任何证据）

> **注：** ~ㄴ/은 것 같다 表示说话者掌握了一些证据。~았/었을 것 같다 则更像是盲目猜测。

---

#### 그렇다 +  것 같다— 大概 / 我觉得是这样
-  **그럴 것 같아요**= 大概 / 我觉得是这样 / 看来是这样
-  **그런 것 같아요**= 大概（现在时）

| 韩语 | 英语 |
|--------|---------|
| 엄마가 어디에 있어요? 병원에 갔어요? —  **그럴 것 같아요**| 妈妈在哪儿？她去医院了吗？ — 大概吧 |
| 수영장물이 다 넘쳤어요? —  **그런 것 같아요**| 水都溢出来了嗎？ — 大概吧 |

---

#### ~겠다 — 表达可能性
用于根据观察到的证据，表示某事“必定是”或“将会是”某种情况。

| 韩语 | 英语 |
|--------|---------|
| **맛있겠다!** | 那一定很好吃！（看着食物） |
| **배고프겠다!** | 你一定饿了！ |
| **힘들겠다!** | 那一定很难吧！ |
| **아프겠다!** | 那一定很痛！ |
| **배부르겠다!** | 你一定吃饱了吧！ |
