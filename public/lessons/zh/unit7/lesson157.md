- **경우** = 情况或情况(그럴 경우 在那种情况下... 같은 경우 在这样的情况下)

- **중증** = 严重疾病
- **포로** = 囚犯数
- **적군** = 敌军
- **물가** = 货物价格

- **통신** = 通讯

## 경우 - 某种情况或情况

경우 指特定的情况或情况。 类似 때 (Lesson 42)但更具体地提请注意这一情况。

### 描述 경우 带有名词

附 录 ~의 到名词之前 경우,译:"以(名). "

- **한국의 경우** 물가가 매년 조금씩 오르고 있습니다 = 就韩国而言,货物价格每年略有上涨
- **어린 아이의 경우** 부모가 아이의 옷을 벗겨 줘야 합니다 = 对于年幼的孩子,父母需要帮助他们脱下衣服.
- **정서장애를 앓고 있는 환자의 경우** 정기적인 치료와 가족의 지원이 회복에 큰 도움이 됩니다 = 在患有情绪障碍的病人中,定期治疗和家庭支助大大有助于康复
- **전쟁 포로의 경우** 적군에 의해 발가벗겨진 채 심문을 받을 때도 있습니다 = 就战俘而言,有时他们的衣服被剥光,被敌人审问。

### 带有形容词

- **정서가 불안한 경우에는** 전문 상담사의 도움을 받는 것이 좋습니다 在情绪不稳定的情况下,请专业顾问提供帮助是件好事。
- **통신이 원활하지 않은 경우** 지원 팀에 연락하세요 = 在沟通不畅的情况下,与支助小组联系
- **그 사건과 같은 경우에는** 비슷한 사례를 찾아 보세요 = 在此类情况下,你应寻找类似的案件。
- **그럴 경우** 보통 부자만 돼요 在这种情况下,只有富人才能生存

### 用动词

- 시계 내부의 기어가 **정확히 맞물리지 않은 경우** 시간이 정확하게 맞지 않을 수 있습니다 = 如果时钟内的齿轮没有完全间锁,时间可能不准确.
- **새로운 프로젝트를 벌이는 경우** 예산이 중요합니다 = 启动新项目时,预算很重要。
- **마지못해 하는 경우** 결과가 좋지 않을 수도 있습니다 当做一些不情愿的事时,结果可能不好
- **대규모 행사를 벌이는 경우**, (中文). 준비 과정에서 많은 인력과 자원이 필요합니다 = 在启动大规模活动时,在筹备过程中需要大量人力和资源。
- 멍청이라고 **불리는 경우가** 있어도 자기 자신을 믿어야 합니다 即使你被称为白痴,你必须相信自己
- 의사가 환자의 상태를 확인하기 위해 눈을 **벌리는 경우가** 있습니다 =有医生需要打开病人的眼睛来检查他们的情况.
