# 课程154:~(으页:1려다가 - 我本来想的,但后来

## 词汇

### 名词

- **이상형** = 理想的男女类型
- **한가지** =一种东西
- **초원** = 草原/草地
- **대도시** = 大城市 (中文(简体) ).
- **인상** =毛发眉毛(인상을 찌푸리다 为毛发眉毛
- **먹구름** = 阴云
- **해적** =海盗
- **세면** = 洗脸(세면대 = 沉积, 세면도구 =洗脸用品).
- **미남** 帅哥
- **육식** = 肉类饮食육식동물 = 肉类)
- **채식** = 蔬菜饮食(채식주의자 =素食主义者).
- **여중** = 中学女生
- **여고** = 女子中学
- **저술자** =小说作者

### 动词

- **투입하다** = 用于注射
- **찌푸리다** = 到皱眉

### 形容词

- **선명하다** = 表示清晰/模糊/模糊/vivid
- **상냥하다** = 温柔/招标

## ~(으)려다가

此语法直接缩写为~(으页:1려고 하다가意思是"我本打算做一个特别的行动,但是..." 在实践中,这些句子的开头是"我本来打算...

- 대도시에 **이사하려다가** 비용이 너무 많이 들어서 포기했어요 我本来想搬到大城市,但后来因为太贵而放弃了
- 한가지만 **사려다가** 여러 가지를 샀어요 我本来打算只买一件 但我最后买了几件东西
- 상냥하게 **말하려다가** 화를 내고 말았어요 我本来要轻轻地说话的 但我最后却生气了
- 인상을 **찌푸리려다가** 상냥하게 웃었어요 我本来要眉毛的 但我却轻轻地笑着
- 먹구름이 **끼려다가** 갑자기 해가 나왔어요 黑云即将凝聚 但突然太阳出来了
- 초원에 **가려다가** 날씨가 안 좋아서 포기했어요 我本来要去草地,但我放弃了,因为天气不好
- 사진을 선명하게 **찍으려다가** 카메라를 떨어뜨렸어요 我本来想照清楚的,但我掉了相机
- 여중에서 강연을 **하려다가** 일정이 변경되어 여고로 갔어요 我本来打算在女子中学讲课 但时间安排变了 所以我去了女子中学
- 이 책의 저술자를 **만나려다가** 시간이 안 맞아서 못 만났어요 我本来要见那本书的作者 但时机不对 所以我不能见他
- 동전을 자판기에 **투입하려다가** 기계가 고장 난 것을 알았어요 我本来打算把硬币插入自动售货机 当我意识到硬币坏了
- 세면도구를 **챙기려다가** 친구가 가져올 것 같아서 안 챙겼어요 我本来要带洗脸用品的 但我的朋友可能要带这些
- 매일 육식을 **먹으려다가** 건강을 위해서 채식으로 바꾸었어요 我本来每天都要吃肉 但为了健康 我把它改成蔬菜
- 새 장치를 **설치하려다가** 기존 장치가 아직 쓸 만해서 그냥 두었어요 =我本来要安装新设备,但现有的设备仍然可以使用,所以我离开了原样.
- 해적에 관한 이야기를 동생에게 **하려다가** 너무 무서울까 봐 그만뒀어요 我本来要讲一个海盗的故事,但我停下来是因为我认为这是太可怕了
