# 课程155:~(으页:1려는 - 描述即将到来的名词려고 하다

## 词汇

### 名词

- **읍** = 指农村的小镇(읍내 =一个小镇的小市区).
- **구어** = 口语
- **압정** = 缩略语
- **대원** = 为群体工作的工人(구조대원 = 救援人员)
- **비법** = 秘密过程
- **정규** =经常(정규직 = 经常职位)
- **비정규** = 不规则(비정규직 =非正规工人)
- **현수막** =旗帜挂在外面
- **인공호흡** =人工呼吸(CPR)
- **인공호흡기** = 人工呼吸器

### 动词

- **팔리다** = 将出售
- **공개하다** = 公开
- **세척하다** = 净化(식기세척기 我还得说
- **지지하다** = 支持/支持某个人
- **취침하다** 去睡觉
- **발급하다** = 发行
- **전환하다** = 改变方向

### 副词

- **통** = 电话柜台(전화 한 통 =一个电话)
- **힘껏** 只要有力量 我就会去

## ~(으)려는

~ ([으页:1려는 是 ~ () 的缩写으页:1려고 하는,用于描述即将出现的名词,其含义是"谁打算"或"谁正在尝试".

- 엄마 모르게 읍내에 **가려는** 계획을 세웠어요 我做了一个计划 去小镇,没有妈妈知道
- 구어를 **배우려는** 학생들이 많이 있어요 很多学生想学口语
- 압정을 **사용하려는** 사람들이 많아서 압정이 금방 다 팔렸어요 很多人想用缩图 所以他们很快就卖光了
- 그 음식의 비법을 **공개하려는** 요리사가 드디어 나타났어요 厨师想要揭开秘密过程 终于出现了
- 위급 환자에게 인공호흡을 **하려는** 응급 대원이 도착했어요 = 准备进行心肺复苏的急救人员已抵达
- 인공호흡기를 **사용하려는** 의사가 준비 중이에요 即将使用人工呼吸器的医生准备好了
- 정규 수업에 **참석하려는** 학생들이 줄을 섰어요 = 想要参加正规班级的学生排队
- 정규직으로 **취업하려는** 사람들이 많아서 경쟁이 치열해요 竞争激烈 因为很多人想得到一个固定的职位
- 회사에서 비정규직에서 정규직으로 모든 직원들을 **전환하려는** 움직임이 있어요 =公司有将所有非正规工人改为正规工人的运动.
- 현수막을 **걸려는** 사람들이 이른 아침부터 준비하고 있어요 想挂旗子的人从清晨就开始准备
- 힘껏 운동장에서 **뛰려는** 아이들이 쉬는 시간이 시작되자마자 나왔어요 想要在操场上跑步的孩子们 刚开始休息就出来了

## ~(으)려던

~ ([으页:1려던 使用 ~던 来描述一个名词 本来要发生但没发生

- 과일을 **세척하려던** 순간에 물이 다 떨어졌어요 就像我正要清理水果一样 我们没水了
- 후보자를 **지지하려던** 사람들은 예상하지 못한 발표에 당황했어요 = 即将支持候选人的人对一个出乎意料的公告感到惊讶.
- 일찍 **취침하려던** 계획이 전화 한 통 때문에 엉망이 됐어요 我早点上床的计划被电话打断了
- 새 여권을 **발급하려던** 사람들은 시스템 오류로 기다려야 했어요 = 即将签发新护照的人由于系统错误不得不等待.
