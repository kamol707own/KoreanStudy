# 第161课:用~形容即将到来的名词.느냐는

### 名词

- **굴** =牡蛎(굴밥 =牡蛎大米).
- **쇠** =铁(열쇠 =键, 쇠사슬 =链, 자물쇠 = 锁定)
- **층간** = 楼层之间(층간 소음 = 地板之间的噪音)
- **여정** = 行程
- **괴물** =怪物
- **진주** = 珍珠类(진주목걸이 =珍珠项链)
- **거부** = 拒绝
- **악마** 恶魔
- **국수** =面条(칼국수 = 平面,( 平面 ) 비빔국수 =辣面条).
- **관습** = 习惯
- **논란** = 争议、争论
- **주요** = 主,小学

### 动词

- **부식되다** =要腐蚀
- **실행하다** =将执行
- **복귀하다** = 将返回
- **제기하다** 来提出一个问题
- **논의하다** = 讨论

### 形容词

- **청순하다** =纯/无辜
- **정당하다** = 公平无私
- **떠들썩하다** 要吵起来
- **공정하다** = 公平无私

### 副词

- **쿵쿵** = 无名

## ~ ~ 说吧 ~느냐는: 表示即将到来的名词

你可以封装~的意义.느냐 及其上一条通过附加~来描述即将出现的名词.는 改为~느냐。 。 。

- **계획이 실행되느냐 안 되느냐는** 결정을 기다려야 돼요 =我们需要等待是否执行计划的决定。
- 그의 **거부가 정당하냐는** 논의가 이어졌어요 = 关于他的拒绝是否有正当理由的辩论仍在继续。
- 이 **규칙이 공정하냐는** 판단을 내리기 어려워요 很难判断这个规则是否公平
- 그가 **회사에 복귀하냐는** 논의가 계속되고 있어요 =关于他是否会返回公司的讨论正在进行中.
- 쇠가 **부식되냐는** 문제는 산업에서 매우 중요해요 = 铁rod在工业中是否非常重要的问题
- 이 **관습이 언제부터 시작되었냐는** 논쟁이 많아요 –关于这个习俗何时开始,有很多争论.
- 그가 진심으로 **사과하냐는** 논란의 중심에 있었어요 争议集中在他是否真诚道歉
- 이 **프로젝트가 성공하냐는** 회의의 주요 주제였어요 = 会议的主要议题是该项目能否取得成功
- 우리가 이 **문제를 해결 할 수 있냐는** 논의가 필요해요 = 需要讨论我们是否能够解决这个问题
- 그녀가 정말 **청순하냐는** 소문 때문에 온 동네가 떠들썩했어요 关于她是否真的无辜的谣言 让整个邻居都吵起来了
- 괴물이 정말 **존재하냐는** 의문이 아직도 풀리지 않았어요 =怪物是否真的存在的问题还没有答案.
- 국수가 제대로 **익었냐는** 평가가 요리 대회에서 중요한 기준이었어요 =对面条是否适当烹饪的评价是烹饪比赛的重要标准.
- 우리가 이번 **프로젝트를 제시간에 끝낼 수 있냐는** 질문이 제기되었어요 - 我们能否完成这个项目的问题已经提出
