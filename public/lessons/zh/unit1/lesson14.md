# 第14课：韩语被动语态

来源：[如何学习韩语——第1单元，第14课](https://www.howtostudykorean.com/unit1/unit-1-lessons-9-16/lesson-14-korean-passive-verbs/)

## 主动与被动

| 主动 | 被动 |
|--------|---------|
| 我打开了门 | 门被打开了 |
| 我打开了电脑 | 电脑被打开了 |
| 我尊重我的朋友 | 我的朋友受到尊重 |

> 被动语态动词不能作用于宾语（~을/를 绝不会与它们搭配使用）

## 被动语态的构成

### 하다 →  되다（最常见）

| 主动 | 被动 |
|--------|---------|
|  （포함하다包含） |  포함되다（应包含） |
|  (제공하다提供) |  제공되다(将提供) |
|  （대체하다替换为） |  대체되다（将被替换） |

**示例：**
-  점심이 학교에 준비되었어요= 午餐是由学校准备的
-  기계는 대체되었어요= 机器被更换了

**由谁/什么施事：**
-  에게= 由人
-  에= 由非人
- ~(으)로 = 由工具/方法

### 하다 →  받다（用于与人相关的操作）

| 主动 | 被动 |
|--------|---------|
|  （존경하다尊重） |  존경받다（被尊重） |
|  감동하다（给……留下深刻印象） |  감동받다（被……打动） |

### 非하다动词（独立的被动词）

| 主动 | 被动 |
|--------|---------|
|  켜다（打开） |  켜지다（处于打开状态） |
|  끄다（关闭） |  꺼지다（被关闭） |
|  (닫다已关闭) |  닫히다(即将关闭) |
|  （열다已打开） |  열리다（待打开） |
|  (잠그다锁定) |  잠기다(被锁定) |

### 存在状态：~아/어 있다

对于处于某种“状态”的事物：

| 句子 | 含义 |
|----------|---------|
|  컴퓨터가 켜져 있어요| 计算机处于开机状态 |
| 电视가 꺼져 있어요 | 电视已关闭 |
|  문이 잠겨 있어요| 门锁着 |
|  문이 닫혀 있어요| 门关着 |

### 나다/내다 动词

| 主动 | 被动 |
|--------|---------|
|  （끝내다完成） |  끝나다（待完成） |
|  （고장내다要打破） |  고장나다（被打破） |

**常用表达：**
-  숙제는 끝났어요= 我的作业做完了
-  컴퓨터는 고장 났어요= 电脑坏了
-  기억이 나다= 想起（某段记忆浮现）
-  =생각이 나다 想到（有个主意）
-  냄새가 나다= 很臭
-  화가 나다= 生气

### 添加 ~아/어지다

| 主动 | 被动 |
|--------|---------|
|  (주다给予) |  주어지다(被给予) |
|  （짓다建造） |  지어지다（将要建造） |

> **关键要点：**在韩语中，主动句几乎总是比被动句更自然。
