# 第12课：韩语助词 들, 만, 에서, 부터, 까지, (으)로

来源：[如何学习韩语——第1单元，第12课](https://www.howtostudykorean.com/unit1/unit-1-lessons-9-16/lesson-12/)

## 助词 ~들（复数）

~들 用于表示名词的复数形式，但通常仅用于指人：

- 의사들 = 医生
- 학생들 = 学生
- 배우들 = 演员

> 韩语很少区分单数和复数。  나는 사과를 샀어= 我买了一个苹果（或几个苹果）

## 使用 (몇一些/多少)

몇 将一个数字替换为计数词，表示“一些”：

- 사과 몇 개 = 几个苹果
- 친구 몇 명 = 几个朋友
- 몇 번 = 几次

## 助词 ~만（仅）

~만 表示“仅”，用于替代主语/宾语助词：

| 韩语 | 英语 |
|--------|---------|
|  물만 마셔| 我只喝水 |
|  나는 그 여자만 좋아해| 我只喜欢那个女孩 |
|  사과 한 개만 샀어| 我只买了一个苹果 |
|  공부만 했어요| 我只学了 |

**带位置助词时：**
-  학교에만 갔어요= 我们只去上学
-  =밤에만 운동해요 我只在晚上锻炼

## 助词 ~에서（来自/位于）

~에서 表示某项操作发生的位置：

| 示例 | 含义 |
|---------|---------|
|  학교에서 공부할 거예요| 我将在学校学习 |
|  병원에서 봤어요| 我在医院看到 |
|  한국에서 배웠어요| 我在韩国学到的 |

**也表示“来自”：**
-  캐나다에서 왔어요= 我来自加拿大
-  서울역에서 내릴 거예요= 我将在首尔站下车

> 注意：~에서 不能与 있다. 一起使用。请改用 ~에。

## 连词 ~부터 和 ~까지（从……到/直到）

~부터 = 从（起点）
~까지 = 到/直到（终点）

| 示例 | 含义 |
|---------|---------|
| 3시까지 기다릴 거예요 | 我会等到3:00 |
|  어제부터 아팠어요| 我从昨天开始就不舒服了 |
|  아침부터 밤까지 공부만 했어요| 从早到晚我都在学习 |
|  처음부터 끝까지| 从头到尾 |

## Particle ~(으)로 (With/By/In)

~(으)로 有多种含义：

**1. 工具/方法/材料：**
-  펜으로 썼어요= 我用笔写的
-  차로 갔어요= 我开车去的
-  나무로 지었어요= 我用木头做的

**2. 语言：**
-  한국어로 말했어요= 我用韩语发言
-  영어로 할 거예요= 我将用英语进行

**3. 方向：**
-  집으로 갈 거예요= 我回家
-  오른쪽으로 가세요= 向右走

> ~로 位于元音后，~으로 位于辅音后（除外ㄹ）
