# 第23课：情境中的计数与数字运用

来源：[如何学习韩语——第1单元，第23课](https://www.howtostudykorean.com/unit1/unit-1-lessons-17-25-2/lesson-23/)

## 何时使用哪种计数系统

| 中韩 | 纯韩语 |
|-------------|-------------|
| 金钱 | 计数（物品/人数） |
| 时间单位：分钟 | 时间单位：小时 |
| 电话号码 | 年龄（50岁以下） |
| 月份（名称） | 月份（按序数달） |
| 测量 | 顺序操作 |

## 情境中的计数

| 韩语 | 英语 |
|--------|---------|
|  펜 두 개를 샀어요| 我买了两支笔 |
|  사람 세 명이 왔어요| 来了三个人 |
|  한국에 다섯 번 갔어요| 我去过韩国五次 |
|  차 세 대가 있어요| 我有三辆车 |
|  맥주 두 잔 주세요| 请来两杯啤酒 |

## 在计数器中使用 ~의

数词与计数词的组合可以在名词前加上~의：
-  두 명의 사람= 两个人
-  다섯 개의 펜= 五支笔

> “사람 두 명”这种形式比“두 명의 사람”更常见

## ~번（执行某项操作的次数）

번 用作副词（无需助词）：
-  저는 한국에 세 번 갔어요= 我去过韩国三次
-  저는 오늘 두 번 운동했어요= 今天我锻炼了两次

## 年龄

纯韩语数字 + 살：
-  저는 열여덟 살이에요= 我18岁
- 몇 살이에요? = 你多大了？

## 처음 以及 마지막

| 韩语 | 英语 |
|--------|---------|
|  처음| 第一次/开始 |
|  마지막| 最后（序列中的最后一项） |

- 저는 어제 공항에 처음 갔어요 = 我第一次去了机场
- 이것은 저의 마지막 기회예요 = 这是我的最后一次机会
