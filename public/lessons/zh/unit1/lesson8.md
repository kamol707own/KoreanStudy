## 韩语副词

副词用来表示某件事发生在**何时**、**何地**或**程度如何**。

### “时间与地点”副词

在句子中插入表示时间或地点的词时，必须添加助词**에**。

| 规则 | 示例 |
|------|---------|
| 地点 ~에 | 병원**에**  갔어요(我去医院了) |
| 时间 ~에 | 화요일**에**  가겠어요（我周二去） |
| 오늘, 내일,  千万别어제买 ~에 |  （오늘 도착했어요我今天到了） |

> 副词几乎可以放在句子的任何位置，唯独不能放在句尾（句尾必须是动词或形容词）。

### “到什么程度”的副词

这些副词通常放在**动词的正前方**：

| 韩语 | 英语 |
|--------|---------|
|    저는 친구를**자주**만나요| 我**经常**和朋友见面 |
|    저는 밥을**많이**먹었어요| 我吃了**很多**米饭 |
|    저는 집에**바로**갔어요| 我**立刻**回了家 |
|    저는 숙제를**빨리**했어요| 我**很快**就完成了作业 |

### 用形容词造副词

| 词性 | 形容词 | 副词 |
|------|-----------|--------|
| 添加 ~게 |  (쉽다简单) |  쉽게(轻松地) |
| 添加 ~게 |  (비슷하다类似) |  비슷하게(同样) |
| 添加 ~게 |  (다르다不同) |  다르게(不同地) |
| 改为하다 ~히 |  조용하다(安静地) | 조용히/조용하게 (安静地) |
| 更改为하다 ~히 |  안전하다(安全) | 안전히/안전하게 (安全地) |
| 特殊形式 |  (많다许多) |  많이(很多) |
| 特殊形式 |  (빠르다快) |  빨리(迅速) |

**例句：**
-  저는 조용하게 먹었어요= 我安静地吃了饭
-  저는 거리를 안전하게 건넜어요= 我安全地过马路了
-  저는 행복하게 살았어요= 我过得很幸福

## 否定句

将句子变为否定句有两种方法：

### 方法 1：안（副词）

置于最后一个动词或形容词的**안**正前方：

| 韩语 | 英语 |
|--------|---------|
|  그 여자는 안 예뻐요| 那个女孩不漂亮 |
|  저는 생선을 안 좋아해요| 我不喜欢吃鱼 |
|  저는 내일 학교에 안 가겠어요| 我明天不去上学了 |

### 方法 2：~지 않다（动词）

在最后一个动词/形容词的词干后加上 **~지 않다**：

| 韩语 | 英语 |
|--------|---------|
|  그 여자는 예쁘지 않아요| 那个女孩不漂亮 |
|  저는 생선을 좋아하지 않아요| 我不喜欢吃鱼 |
|  저는 내일 학교에 가지 않겠어요| 明天我不去上学了 |

> 这两种方法的含义完全相同。通过实践，你会逐渐形成在不同情况下该使用哪一种的偏好。

### 关于含~하다动词的否定句的说明

对于以~하다结尾的动词，通常会将~하다与名词分开，并在它们之间안插入一个：

| 正确 | 不够自然 |
|---------|-------------|
| 저는 공부를 **안** 했어요 | 저는 **안** 공부했어요 |
| 저는 실수를 **안** 했어요 | 저는 **안** 실수했어요 |
| 저는 여행을 **안** 했어요 | 저는 **안** 여행했어요 |

对于以 ~하다 结尾的形容词，不能将 ~하다 拆开。请将 ~ 放在该词안前面，或直接使用 ~지 않다：

| 正确 | |
|---------|---|
|  저는 안 행복해요| 我不高兴 |
|  저는 행복하지 않아요| 我不高兴 |

> 你不能说：  저는 행복을 안 해요（错误）

## 不是： 아니다

**아니다** 与……相反**이다**，但用法不同。助词**~이/가**附着在名词上，而……아니다则是独立的：

| 韩语 | 变位 |
|--------|-----------|
| 나는 선생님이 아니다 | 저는 선생님이 아니에요 |
| 나는 너의 친구가 아니다 | 나는 너의 친구가 아니야 |
| 나는 대학생이 아니다 | 저는 대학생이 아니에요 |

## 没有： 없다

**없다** 是……的反义词**있다**：

| 韩语 | 英语 |
|--------|---------|
|  저는 돈이 없어요| 我没钱 |
|  저는 시간이 없어요| 我没时间 |
|  우리는 차가 없어요| 我们没有车 |
|  저의 친구는 지금 한국에 없어요| 我的朋友现在不在韩国 |

## 不喜欢：  和싫어하다 싫다

| 词语 | 类型 | 用法 |
|------|------|-------|
|  싫어하다| 动词 |  싫어해요(我不喜欢) — 可带宾语 |
|  싫다| 形容词 |  싫어요（我不喜欢）——使用 ~이/가 |

| 韩语 | 英语 |
|--------|---------|
|  저는 과일을 싫어해요| 我不喜欢水果（动词） |
|  저는 과일이 싫어요| 我不喜欢水果（形容词） |

> 注意不要使用双重否定：  저는 과일을 싫어하지 않아요= 我并不讨厌水果（表达不自然）
