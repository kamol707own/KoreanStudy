# 第24课：Before/After、From/Until 及时间表达

来源：[如何学习韩语——第1单元，第24课](https://www.howtostudykorean.com/unit1/unit-1-lessons-17-25-2/lesson-24/)

## ~기 전에（之前）

- 밥을 먹기 전에 손을 씻어요 = 吃饭前要洗手
- 집에 가기 전에 숙제를 했어요 = 回家前我写了作业
- 시험을 보기 전에 복습해야 돼요 = 我需要在考试前复习一下

## ~ㄴ/은 후에（之后）

- 밥을 먹은 후에 커피를 마셨어요 = 我饭后喝了咖啡
- 한국에 온 후에 한국어를 배웠어요 = 来到韩国后，我学会了韩语
- 수업이 끝난 후에 만날 거예요 = 下课后我们再见

## ~아/어서（因为）

- 비가 와서 집에 있었어요 = 因为下雨，我待在家里
- 배가 고파서 밥을 먹었어요 = 我饿了，所以吃了东西
- 너무 추워서 문을 닫았어요 = 我关上门，因为太冷了

## ~아/어서는 안 되다（不应）

- 여기서는 안 돼요 = 这里不允许这样做
- 숙제를 안 하면 안 돼요 = 你不应该不做作业
- 늦게 자면 안 돼요 = 你不应该睡懒觉

## ~아/어야 하다（必填）

- 내일 일찍 일어나야 해요 = 我明天必须早起
- 숙제를 해야 해요 = 我必须做作业
- 한국어를 열심히 공부해야 해요 = 我必须努力学习韩语

## 전 以及  후（时间表达式）

| 韩语 | 英语 |
|--------|---------|
| 3시간 전 | 3小时前 |
| 3시간 후 | 3小时后 |
| 3일 전 | 3天前 |
| 3일 후 | 3天后 |

- 저는 3시간 전에 도착했어요 = 我3小时前到了
- 저는 3일 후에 떠날 거예요 = 我将在3天后离开
