# 第21课：用韩语提问

来源：[如何学习韩语——第1单元，第21课](https://www.howtostudykorean.com/unit1/unit-1-lessons-17-25-2/lesson-21-asking-questions-in-korean-why-when-where-and-who/)

## 疑问词

| 韩语 | 英语 | 示例 |
|--------|---------|---------|
| 뭐/무엇 | 什么 | 이게 뭐예요? = 这是什么？ |
|  누구| 谁 | 그 사람은 누구예요? = 那是谁？ |
|  어디| 哪里 | 어디에 가요? = 你要去哪里？ |
|  언제| 什么时候 | 언제 왔어요? = 你什么时候来的？ |
|  왜| 为什么 | 왜 안 왔어요? = 你为什么没来？ |
|  어떻게| 怎么 | 어떻게 해요? = 你是怎么做的？ |
|  얼마| 多少钱 | 얼마예요? = 多少钱？ |
|  몇| 多少 | 몇 개 있어요? = 有多少个？ |

## 疑问句的构成

韩语疑问句的词序与陈述句相同。在句末加上“~요”，并采用上扬语调：

- 이거 뭐예요? = 这是什么？
- 어디에 가요? = 你要去哪儿？
- 언제 와요? = 你什么时候来？

## 嵌入式问题

当一个疑问句包含在另一个句子中时：

- 그가 언제 오는지 알아요? = 你知道他什么时候来吗？
- 어디에 가는지 모르겠어요 = 我不知道（他/她）要去哪里

## ~ㄹ/을 때 (何时)

用于表示“当”某事发生时：

- 한국에 있을 때 한국어를 배웠어요 = 我在韩国的时候，学了韩语
- 점심을 먹을 때 젓가락을 써요 = 吃午饭时，请用筷子
- 어렸을 때 강아지를 키우고 싶었어요 = 我小时候，想养一只小狗
