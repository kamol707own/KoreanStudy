# 第 10 课：韩语数字

资料来源：[如何学习韩语 - 第 1 单元，第 10 课](https://www.howtostudykorean.com/unit1/unit-1-lessons-9-16/unit-1-lesson-10/)

## 中韩数字（源自中文）

|数量 |韩语 |
|--------|--------|
| 0 | 영/공 |
| 1 | 일 |
| 2 | 이 |
| 3 | 삼 |
| 4 | 사 |
| 5 | 오 |
| 6 | 육 |
| 7 | 칠 |
| 8 | 팔 |
| 9 | 구 |
| 10 | 십 |
| 100 | 백 |
| 1,000 | 천 |
| 10,000 | 만 |

**创建更大的数字：**
- 11 = 십일 (10+1)
- 20 = 이십 (2×10)
- 21 = 이십일 (2×10+1)
- 100 = 백
- 900 = 구백 (9×100)
- 5,000 = 오천 (5×1000)

**用于：**计数/处理金钱、测量、数学、电话号码、时间分钟、月份名称、计算月份

## 柜台

|专柜|用途 |示例|
|---------|-------|---------|
| 개 |事物|펜 두 개（两支笔）|
| 명 |人们|사람 두 명（两个人）|
| 번 |行动/行为|세 번（三次）|
| 대 |汽车|차 세 대（三辆车）|
| 잔 |眼镜|맥주 두 잔（两杯啤酒）|

**计数器的数字变化：**
- 하나 → 한 (한 개)
- 둘 → 두 (두 명)
- 셋 → 세 (세 번)
- 넷 → 네 (네 개)
- 스물 → 스무 (스무 명)

## 零

|词|用途 |
|------|-------|
| 영 |分数/分数、温度、数学|
| 공 |电话号码|

## 报时

- **时间：** 纯韩语数字 + 시: 두 시 = 2:00
- **分钟：**中韩数字+분:삼십 분 = 30分钟
- **全日制：** 두 시 삼십 분 = 2:30

**示例：** 저는 5시에 먹을 거야 = 我将在 5:00 吃饭

## 年龄

纯韩语数字 + 살: 저는 열 살이에요 = 我10岁

> 50岁以后，中韩号码比较常用。
