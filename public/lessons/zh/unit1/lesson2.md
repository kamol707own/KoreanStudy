# 第2课：韩语助词 이/가

来源：[如何学习韩语——第1单元，第2课](https://www.howtostudykorean.com/unit1/unit-1-lessons-1-8/unit-1-lesson-2/)

## 词汇

### 名词

| 韩语 | 英语 | 常见用法 |
|--------|---------|---------------|
|  나라| 国家 |  우리 나라(我国/韩国) |
|  가방| 包/背包 |  가방을 매다（装进背包） |
|  창문| 窗口 |  창문을 열다（打开窗口） |
|  잡지| 杂志 |  잡지를 읽다(阅读杂志) |
|  방| 房间 |  방이 좁다（房间很小） |
|  냉장고| 冰箱 |  냉장고에 넣다（放进冰箱） |
|  개| 狗 |  강아지(幼犬/宠物狗) |
|  고양이| 猫 |  고양이는 의자 밑에 있어요(猫在椅子底下) |
|  쥐| 大鼠、小鼠 |  쥐는 너무 더러워요（大鼠非常脏） |
|  펜| 笔 |  펜으로 쓰다(用笔写) |
|  전화기| 电话 |  핸드폰（手机，更常用） |
|  커피| 咖啡 |  커피를 마시다(喝咖啡) |
|  식당| 餐厅 |  한식당(韩式餐厅) |
|  건물| 建筑物 |  건물 내에（建筑物内部） |
|  텔레비전| 电视 |  텔레비전을 보다（看电视） |
|  미국| 美国 |  미국 사람(美国) |
|  캐나다| 加拿大 |  캐나다 사람(加拿大) |
|  호텔| 酒店 | 5성급 호텔（五星级酒店） |
|  학교| 学校 |  학교를 다니다（上学） |
|  은행| 银行 |  은행원(银行家) |

### 副词（位置词）

| 韩语 | 英语 | 示例 |
|--------|---------|---------|
|  안| 室内 |  집 안에（屋内） |
|  위| 排在首位 |  탁자 위에（位于表格顶部） |
|  밑| 下方 |  의자 밑에（椅子下方） |
|  옆| 旁边 |  학교 옆에（学校旁边） |
|  뒤| 后面 |  학교 뒤에（学校后面） |
|  앞| 前面 |  집 앞에（房子前面） |
|  여기| 这里 | 여기에 빨리 오세요!（快过来！） |

### 动词

| 韩语 | 英语 | 注释 |
|--------|---------|-------|
|  있다| 身处某地 |  은행에 있어요(我正在银行) |
|  있다| 拥有某物 |  펜이 있어요(我有一支笔) |

## 있다: 拥有

있다 作为形容词表示“拥有”时——宾语后接 **~이/가**（而非 ~을/를）：

| 示例 | 变位 |
|---------|-----------|
| 나는 펜이 있다 | 저는 펜이 있어요 |
| 나는 차가 있다 | 저는 차가 있어요 |
| 나는 잡지가 있다 | 저는 잡지가 있어요 |
| 나는 가방이 있다 | 저는 가방이 있어요 |

## 地点/时间标注：~에

助词 **~에** 表示地点或时间：

| 英语 | 韩文版 |
|---------|---------------|
| 我在学校 |  나는 학교에 있다|
| 我去了公园 |  나는 공원에 갔어요|
| 我在10:00吃了饭 |  나는10시에 먹었어요 |

## 있다: 位于某地

| 示例 | 变位 |
|---------|-----------|
| 나는 학교에 있다 | 저는 학교에 있어요 |
| 나는 캐나다에 있다 | 저는 캐나다에 있어요 |

**带方位词的：**

| 韩语 | 英语 |
|--------|---------|
|  나는 학교 앞에 있다| 我在学校门口 |
|  나는 학교 뒤에 있다| 我在学校后面 |
|  나는 학교 옆에 있다| 我在学校旁边 |
|  나는 은행 안에 있다| 我在银行里 |
|  개는 집 안에 있다| 狗在屋里 |
|  고양이는 의자 밑에 있다| 猫在椅子底下 |

> 请注意这两者之间的显著区别：학교**가**  있다= 我有一所学校 vs. 학교**에**  있다= 我在学校

## ~이/가 作为主题标记

**~이/가** 与 **~는/은** 一样，被添加到句子的主语后。

| 示例 | 含义 | 细微差别 |
|---------|---------|--------|
|  고양이는 집 뒤에 있다| 猫在房子后面 | 与其他事物进行比较 |
|  고양이가 집 뒤에 있다| 猫在房子后面 | 只是陈述一个事实 |

> ~는/은 具有比较功能——它所修饰的名词正在与其他事物进行比较。~이/가 则只是陈述一个事实，不涉及比较。

**更多示例：**

| 韩语 | 含义 | 语义细微差别 |
|--------|---------|--------|
|  커피가 냉장고에 있다| 咖啡在冰箱里 | 陈述事实 |
|  커피는 냉장고에 있다| 咖啡在冰箱里 | 与桌上的茶相比 |
