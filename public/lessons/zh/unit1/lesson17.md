# 第17课：想要做某事、提问、比较

来源：[如何学习韩语——第1单元，第17课](https://www.howtostudykorean.com/unit1/unit-1-lessons-17-25-2/lesson-17/)

## 想做的事：~고 싶다

附加在动词词干后，表示“想做”：

| 词干 +  고 싶다| 含义 |
|----------------|---------|
|  먹고 싶다| 想吃 |
|  가고 싶다| 想去 |
|  보고 싶다| 想看 / 想念 |
|  하고 싶다| 想做 |

**示例：**
-  저는 밥을 먹고 싶어요= 我想吃东西
-  저는 한국에 가고 싶어요= 我想去韩国
-  저는 그녀가 보고 싶어요= 我想她

**过去：**  가고 싶었어요= 想去

## 提问

疑问句的词序与陈述句相同，且语调上扬：

| 词汇 | 韩语 | 例句 |
|------|--------|---------|
| 什么 |  뭐| 이게 뭐예요? |
| 谁 |  누구| 누구예요? |
| 哪里 |  어디| 어디에 가요? |
| 时间 |  언제| 언제 왔어요? |
| 为什么 |  왜| 왜 안 왔어요？ |
| 如何 |  어떻게| 어떻게 해요? |
| 多少钱 |  얼마| 얼마예요？ |

## 比较：~보다

~보다 = “比……更……”（比较）：

- 저는 형보다 키가 커요 = 我比我哥哥高
- 한국어는 영어보다 어려워요 = 韩语比英语难
- 택시는 버스보다 빨라요 = 出租车比公交车快
