## 怎样说“我”或“我”

|韩语 |用途 |当附加 ~가 时 |
|--------|-------|---------------------|
| 저 |正式的“我/我”| 제 (제가) |
| 나 |非正式的“我/我”| 내 (내가) |

- ~는 已附加 → 저는 / 나는 （主题）
- ~를 附加 → 저를 / 나를 （对象）
- ~가 附加 → 제가 / 내가 （主语/从句）

## 怎么说“你”

韩国人很少直接说“你”。相反，他们使用：
- 职务：부장님（老板）、교장선생님（校长）
- 家庭用语：오빠（哥哥）、언니（姐姐）
- 아저씨/아주머니（先生/女士，适用于陌生人）
- 너（非正式的“你”）
- 당신（“你”——母语人士很少使用）

## 基本动词变化：过去、现在、将来

> **重要提示：** 这些词形变化（普通形式/日记形式）很少在对话中使用。它们用于书籍、测试、文章和日记中。您将在第 6 课中学习会话形式。

### ~아/어 的规则

如果词干中的最后一个元音是 **ㅏ 或 ㅗ** → 添加 **~아**
如果最后一个元音是**其他** → 添加 **~어**
如果词干以 **하다** 结尾 → 添加 **~여 (해)**

## 动词

### 现在时

|词干结尾 |规则|示例|
|-------------|------|---------|
|辅音|添加 ~는다| 먹다 → 먹는다, 닫다 → 닫는다 |
|元音|添加 ~ㄴ다| 배우다 → 배운다, 가다 → 간다 |

### 过去时

将 **~았/었다** 添加到词干：

|词|茎|过去时|
|------|------|-----------|
| 먹다 | 먹 | 먹었다 |
| 닫다 | 닫 | 닫았다 |
| 배우다 | 배우 | 배웠다 |
| 가다 | 가 | 갔다 |
| 오다 | 오 | 왔다 |
| 던지다 | 던지 | 던졌다 |
| 건너다 | 건너 | 건넜다 |
| 만나다 | 만나 | 만났다 |
| 공부하다 | 공부하 | 공부했다 |

**合并规则：**
- 아 + 아 = 아 (가 + 았다 = 갔다)
- 오 + 아 = 와 (오 + 았다 = 왔다)
- 우 + 어 = 워 (배우 + 었다 = 배웠다)
- 하 + 여 = 해 (공부하다 + 였다 = 공부했다)

### 将来时

将 **~겠다** 添加到词干（所有词干相同）：

|词|未来 |
|------|--------|
| 먹다 | 먹겠다 |
| 가다 | 가겠다 |
| 배우다 | 배우겠다 |

### 动词变位表

|动词|过去 |现在 |未来 |
|------|------|---------|--------|
| 먹다 | 먹었다 | 먹는다 | 먹겠다 |
| 닫다 | 닫았다 | 닫는다 | 닫겠다 |
| 배우다 | 배웠다 | 배운다 | 배우겠다 |
| 가다 | 갔다 | 간다 | 가겠다 |
| 이해하다 | 이해했다 | 이해한다 | 이해하겠다 |
| 오다 | 왔다 | 온다 | 오겠다 |
| 던지다 | 던졌다 | 던진다 | 던지겠다 |

## 形容词

### 现在时

**什么也不做！** 保持形容词不变——它已经变位了。

- 그 선생님은 아름답다=那个老师很漂亮
- 그 길은 길다 = 那条街很长
- 나의 손은 크다 = 我的手很大

### 过去时

与动词相同的规则 - 添加 ~았/었다：

|形容词|过去时|
|-----------|-----------|
| 길다 | 길었다 |
| 좋다 | 좋았다 |
| 비싸다 | 비쌌다 |
| 잘생기다 | 잘생겼다 |
| 뚱뚱하다 | 뚱뚱했다 |

### 将来时

添加***~겠다**：

|形容词|未来 |
|-----------|--------|
| 행복하다 | 행복하겠다 |
| 맛있다 | 맛있겠다 |
| 배고프다 | 배고프겠다 |

## 있다 和 있는다

**있다 是形容词**，意思是“拥有”或“位于某个位置”——现在时仍为 있다。

**있다 在某些语法上下文中是动词**（在后面的课程中介绍），其中现在时变为 있는다。
