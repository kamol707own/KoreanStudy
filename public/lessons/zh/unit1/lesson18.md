# 第18课：~아/어 있다（处于某种状态）

来源：[如何学习韩语——第1单元，第18课](https://www.howtostudykorean.com/unit1/unit-1-lessons-17-25-2/lesson-18/)

## ~아/어 있다（存在状态）

附加在动词词干上，用于表示处于某种结果状态：

| 动词 | 状态式 | 含义 |
|------|-----------|---------|
|  서다|  서 있다| 站着 |
|  앉다|  앉아 있다| 坐着 |
|  눕다|  누워 있다| 指躺着 |
|  열다|  열려 있다| 待开放 |
|  닫다|  닫혀 있다| 将关闭 |
|  잠그다|  잠겨 있다| 将被锁定 |

**示例：**
-  문이 열려 있어요= 门是开着的
-  저는 의자에 앉아 있어요= 我正坐在椅子上
-  컴퓨터가 켜져 있어요= 电脑开着

## 行动与国家

| 句子 | 含义 |
|----------|---------|
|  문을 열었어요| 我打开了门（动作） |
|  문이 열려 있어요| 门是开着的（状态） |

## ~아/어 지다 (成为)

| 形容词 | 变位形式 | 含义 |
|-----------|------------|---------|
|  크다|  커지다| 变大 |
|  덥다|  더워지다| 变得更热 |
|  좋다|  좋아지다| 变得更好 |

**示例：**
-  날씨가 추워졌어요= 天气变冷了
-  집 값이 비싸지고 있어요= 房价越来越贵了
