# 第16课：名词 + ~적, ~적으로, ~적이다, ~스럽다

来源：[如何学习韩语——第1单元，第16课](https://www.howtostudykorean.com/unit1/unit-1-lessons-9-16/lesson-16/)

## ~적（与……有关的／具有……的性质）

添加到汉语源名词后，可形成描述性词语：

| 名词 | +적 | 翻译 |
|------|-----|-------------|
|  문화(文化) |  문화적| 文化 |
|  경제(经济) |  경제적| 经济的 |
|  역사(历史) |  역사적| 历史 |
|  과학(科学) |  과학적| 科学的 |
|  충동(冲动) |  충동적| 冲动的 |
|  민주(民主) |  민주적| 民主的 |
|  개인(个人) |  개인적| 个人 |

## ~적으로（副词形式：-ly）

| 形容词 | 副词 |
|-----------|--------|
|  문화적|  문화적으로（文化上） |
|  경제적|  경제적으로（经济上） |
|  역사적|  역사적으로（历史上的） |
|  과학적|  과학적으로（从科学角度看） |
|  충동적|  충동적으로（一时冲动） |
|  민주적|  민주적으로（民主地） |

**示例：**
-  한국과 미국은 역사적으로 좋은 관계가 있다= 从历史上看，韩国和美国一直保持着良好的关系
-  그들은 그 문제를 과학적으로 풀었다= 他们以科学的方式解决了这个问题

## ~적이다（形容词形式）

加上  后，它就이다成为一个可以作句子谓语的形容词：

- 미국은 민주적인 나라예요 = 美国是一个民主国家
- 저 학교는 역사적인 건물이에요 = 那所学校是一座历史建筑
- 이것은 과학적인 문제예요 = 这是一个科学问题

> ~적 是名词；~적이다 是形容词。~적이다 的用法更为常见。

## ~스럽다 （具有……的特性）

加在名词后形成形容词：

| 名词 | +스럽다 | 翻译 |
|------|---------|-------------|
|  사랑(爱) |  사랑스럽다| 可爱的 |
|  자연(自然) |  자연스럽다| 自然的 |
|  실망(失望) |  실망스럽다| 令人失望 |
|  만족(满意度) |  만족스럽다| 满意 |
|  자랑(自豪) |  자랑스럽다| 自豪 |

**示例：**
-  그 여자는 사랑스러워요= 那个女孩真可爱
-  그는 한국어를 자연스럽게 말해요= 他说韩语很流利
-  결과는 실망스러웠어요= 结果令人失望
-  저는 우리 아들이 자랑스러워요= 我为我们的儿子感到自豪

**副词形式（~게）：**
-  자연스럽게= 自然地
-  사랑스럽게= 亲切地
-  실망스럽게= 令人失望地

## 실망하다 vs 실망스럽다

| 词汇 | 类型 | 用法 |
|------|------|-------|
|  실망하다| 动词（情感） |  저는 실망했어요= 我感到失望 |
|  실망스럽다| 形容词（事物） |  결과는 실망스러웠어요= 结果令人失望 |

> 실망하다: 表达“对……感到失望”时，使用 ~에게/한테（指人）或 ~에（指非人）
> 실망스럽다: 采用“主语-宾语-形容词”的句式

## 만족하다 vs） 만족스럽다

与以下表达方式相同실망：
-  저는 만족해요= 我很满意
-  결과는 만족스러웠어요= 结果令人满意
-  저는 결과가 만족스러웠어요= 我对结果很满意
