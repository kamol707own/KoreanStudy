# 更多韩语基础字母

来源：[如何学习韩语——第0单元，第2课](https://www.howtostudykorean.com/unit0/0-lesson-2/)

在上一节课中，我们学习了韩语字母表中最基础的字母。在继续学习之前，还有一些字母需要你先弄明白。

## 那封信 ㅇ

你将要学习的第一位新字母是： **ㅇ**

当  **ㅇ**位于音节开头（第1位）时，它**不发音**，首先发出的音是元音：

| 音节 | 罗马化 |
|----------|-------------|
|  안| an |
|  운| un |
|  온| 于 |
|  업| eob |

当  **ㅇ**位于音节末尾（第3位）时，其发音为**“ng”**，如“walki**ng**”中的发音：

| 音节 | 罗马化 |
|----------|-------------|
|  강| kang |
|  방| bang |
|  깅| 国王 |
|  공| kong |

该字母既**ㅇ**可以放在第1位，也可以放在第3位： =**앙** ang

## 新的辅音组合

### ㄱ 集合

| 韩语 | 罗马化 | 描述 |
|--------|-------------|-------------|
|  ㄱ| k | 原文 |
|  ㄲ| kk | 双辅音，发音更费力 |
|  ㅋ| k | 带送气音，发音更接近英语中的“k” |

### ㅂ 集合

| 韩语 | 罗马字母转写 | 描述 |
|--------|-------------|-------------|
|  ㅂ| b | 原文 |
|  ㅃ| bb | 双辅音，发音更紧 |
|  ㅍ| p | 带送气音，更接近英语中的“p” |

### ㅈ 集合

| 韩语 | 罗马音 | 描述 |
|--------|-------------|-------------|
|  ㅈ| j | 原文 |
|  ㅉ| jj | 双辅音，发音更紧 |
|  ㅊ| ch | 带送气音，发音更接近英语中的“ch” |

### ㄷ 集合

| 韩语 | 罗马化 | 描述 |
|--------|-------------|-------------|
|  ㄷ| d | 原文 |
|  ㄸ| dd | 双辅音，发音更紧 |
|  ㅌ| t | 带送气音，发音更接近英语中的“t” |

### ㅅ 集合

| 韩语 | 罗马字转写 | 说明 |
|--------|-------------|-------------|
|  ㅅ| s | 原文 |
|  ㅆ| ss | 双辅音，发音更紧 |

### 音节示例

| 组合 | 结果 | 罗马音 |
|-------------|--------|--------------|
|  ㄸ+  ㅏ+  ㅇ|  땅| ddang |
|  ㅌ+  ㅗ+  ㅇ|  통| tong |
