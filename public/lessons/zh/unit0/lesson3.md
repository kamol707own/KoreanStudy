# 韩语双元音：复合元音

来源：[如何学习韩语——第0单元，第3课](https://www.howtostudykorean.com/unit0/unit-0-lesson-3/)

在本单元（第0单元）的最后一课中，你将学习阅读韩语所需的其余元音。这些字母大多被称为“双元音”——这只是个花哨的说法，其实就是指一个音节中包含两个元音。

## 基本元音复习

| 韩语 | 罗马化 |
|--------|-------------|
|  ㅏ| a |
|  ㅓ| eo |
|  ㅜ| u |
|  ㅗ| o |

## 带“Y”的元音

在每个元音上再加一条横线，就会产生“Y”的发音：

| 韩语 | 罗马字母转写 | 示例 |
|--------|-------------|---------|
|  ㅑ| ya |  약= yak |
|  ㅕ| yeo |  역= yeok |
|  ㅠ| yu |  육= yuk |
|  ㅛ| yo |  욕= yok |

## ㅐ 以及 ㅔ

| 韩语 | 罗马字母转写 | 备注 |
|--------|-------------|-------|
|  ㅐ| ae | 发音类似于“weigh”中的“eigh” |
|  ㅔ| e | 发音与  ㅐ|

> 在现代韩语听众耳中， ㅐ和 的ㅔ发音完全一样。从实际应用的角度来看，特别是对于学习韩语的外国人而言，这两者的发音是完全相同的。

**示例：**
-  배= bae（发音类似于“bay”）
-  베= be（发音也类似于“bay”）

**音频示例：**
-  含ㅐ辅音： 애, 배, 재, 대, 개, 새, 매, 내, 해, 
래-  含ㅔ辅音： 에, 베, 제, 데, 게, 세, 메, 네, 헤, 레

> （是的，它们完全一样——ㅐ而且听ㅔ起来也完全一样）

## 复合元音

| 组合 | 结果 | 罗马化 | 示例 |
|-------------|--------|-------------|---------|
|  ㅜ+  ㅣ|  ㅟ| wi |  쥐|
|  ㅜ+  ㅓ|  ㅝ| wo |  원|
|  ㅗ+  ㅣ|  ㅚ| oe（发音类似“way”） |  외국|
|  ㅗ+  ㅏ|  ㅘ| wa |  완|
|  ㅡ+  ㅣ|  ㅢ| ui |  의|
|  ㅕ+  ㅣ|  ㅖ| ye |  예|

**复合元音音节：**

| 韩语 | 罗马化 |
|--------|-------------|
| 위, 뷔, 쥐, 뒤, 귀, 쉬,  뉘| wi |
| 워, 붜, 줘, 둬, 궈, 숴,  눠| wo |
| 외, 뵈, 죄, 되, 괴, 쇠,  뇌| oe |
| 와, 봐, 좌, 돠, 과, 솨,  놔| wa |
| 의, 븨, 즤, 듸, 긔, 싀,  늬| ui |
| 예, 계,  혜| ye |

> 请注意，当使用其中一个“双元音”时，该音节的首个辅音会同时出现在水平排列的字母上方，以及垂直排列的字母左侧。

## 较少见的元音

| 韩语 | 罗马化 | 注释 |
|--------|-------------|-------|
|  ㅙ| wae | 最常见的用法：  왜（为什么） |
|  ㅒ| yae | 最常见的用法：얘기하다（说话） |
|  ㅞ| 我们 | 非常罕见；最常见的是：웨딩（婚礼） |

## 四个字母的音节

一个音节也可能由四个字母组成：一个元音和三个辅音。第三个辅音会紧挨着第二个辅音写在旁边。

**常见示例：**

| 韩语 | 罗马音 | 含义 |
|--------|-------------|---------|
|  닭| 达克 | 鸡 |
|  앉다| antda | 坐 |
|  읽다| ikda | 阅读 |
|  없다| eopda | 没有 |
|  긁다| geulda | 抓挠 |

> 含有这个第四个字母的音节发音稍微复杂一些。其发音取决于接下来的音节是以元音还是辅音开头的。

|  스위치| 切换 |
|  게임| 游戏 |
|  쇼핑| 购物 |
|  오렌지| 橙色 |
|  팀| 团队 |
|  택시| 出租车 |

|  햄버거| 汉堡 |
