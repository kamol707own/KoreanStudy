# 韩语词汇结构与基本字母

来源：[如何学习韩语——第0单元，第1课](https://www.howtostudykorean.com/unit0/unit0lesson1/)

目前，在能够读懂并正确发音韩文字母和音节之前，先别去想单词、语法之类的东西。如果连韩文都读不懂，就很难继续学习这门语言的其他部分。

在第0单元课程中，我会提供韩文字母的罗马化读音。不过，我强烈建议大家一旦掌握了韩文字母的读法，就应该彻底摒弃罗马化读音。例如，今后不要像这样学习：

학교 (hak-kyo) = 学校

你应该这样学习：

학교 = 学校

疯狂地学习这些汉字吧。起初背诵起来虽然很难，但这是必须做的。幸运的是，韩语的“字母表”相当简单，尽管起初对大多数英语使用者来说似乎有些奇怪，因为它与英语完全不同。

> 注：第0单元所教的字母并非按字母顺序排列。而是先介绍最简单的字母，再介绍较复杂的字母。

> 用英文字母来表示韩文字母并没有完美的方法。你经常会看到用“K”和“G”来表示“ㄱ”，用“D”和“T”表示“ㄷ”，或者用“R”和“L”表示“ㄹ”。这些字母都没有完全对应的。 要准确知道一个韩文字母的发音，唯一的方法就是听一听。

## 基本元音

| 韩语 | 罗马化 | 方向 |
|--------|-------------|-------------|
|  ㅣ| i | 垂直 |
|  ㅏ| a | 垂直 |
|  ㅓ| eo | 垂直音（发音类似“uh”） |
|  ㅡ| 欧盟 | 横向 |
|  ㅜ| u | 水平 |
|  ㅗ| o | 水平 |

> 前三个元音是竖着写的，后三个是横着写的。这一点非常重要，因为每个韩文字母的写法都取决于元音是竖着写还是横着写。

## 韩语音节块

韩文是以“块”的形式书写的，每个“块”构成一个音节。一个“块”总是恰好包含一个音节。这些“块”总是按以下其中一种方式书写：

**重要规则：**
1. 数字“2”总是元音
2. 数字“1、3”（有时还有“4”）总是辅音
3. 包含水平书写元音的方块采用特定结构
4. 包含垂直书写元音的方块采用不同的结构

### 示例：书写“bab”

- 步骤 1：判断元音是横向还是纵向。  **ㅏ**是纵向的
- 步骤 2：判断该音节是否以辅音结尾。是 → 需要第 1、2 和 3 位
- 步骤 3：将 (**ㅂ**b) 放进第 1 位，将 (**ㅏ**a) 放进第 2 位，将 (**ㅂ**b) 放进第 3 位

### 练习

| 辅音 | 元音 | 结果 | 罗马化 |
|-----------|-------|--------|--------------|
|  (ㄱk) |  (ㅏa) +  ㄴ(n) |  간| kan |
|  (ㅂb) |  (ㅓeo) +  ㅂ(b) |  법| beob |
|  (ㅈj) |  (ㅜu) |  주| ju |
|  (ㅎh) |  (ㅗo) |  호| ho |
