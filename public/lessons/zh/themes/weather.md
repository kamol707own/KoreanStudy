来源：[如何学习韩语——天气](https://www.howtostudykorean.com/theme/weather/)

## 引言

当你无话可说时，这是最简单的应急话题！大家都喜欢聊天气，尤其是天气不好的时候！

## 句子

### 夏季天气

- 비가 왔어요 = 下雨了 / 下了雨
- 비가 와요 = 下雨了
- 날씨가 너무 더워요 = 天气太热了
- 날씨가 너무 더워서 못 나가요 = 天气太热了，所以我不能出去
- 저는 바다에서 수영하고 싶어요 = 我想去海里游泳
- 저는 해변에 가고 싶어요 = 我想去海滩
- 골프를 치고 있었는데 갑자기 소나기가 왔어요 = 我正在打高尔夫球，突然下起了一阵小雨
- 내일 기온이 30도까지 올라갈 거에요 = 明天的气温将升至30度
- 다음 주까지 폭염이 예상됩니다 = 预计热浪将持续至下周
- 이 방은 냉방 중이다 = 该房间正在开空调
- 한국에서는 장마가 7월에 있어요 = 韩国的7月有雨季
- 장마가 다음 주부터 시작될 거에요 = 雨季将从下周开始
- 날씨가 좋아서 밖에 가고 싶어요 = 我想出去走走，因为天气很好
- 더워서 에어컨을 틀고 싶어요 = 因为天气热，我想开空调
- 더운 날씨가 괜찮은데 습한 날씨가 싫어요 = 天气热没关系，但我讨厌潮湿的天气
- 여름에는 해가 일찍 떠요 = 夏天，太阳升得早
- 여름에는 해가 늦게 져요 = 夏天，日落得很晚
- 날씨가 더워서 물을 많이 마셔야 해요 = 因为天气热，你必须多喝水
- 피부를 보호하기 위해 여름에는 자외선 차단제를 발라 야 돼요 = 为了保护皮肤，夏天需要涂抹防晒霜

### 秋季天气

- 단풍이 예뻐요 = 这些叶子真漂亮
- 낙엽 때문에 산길이 미끄러워요 = 山路因落叶而湿滑
- 날씨가 서늘해요 = 天气凉爽
- 날씨가 쌀쌀해요 = 天气有点冷
- 하늘이 매우 맑아요 = 天空非常晴朗
- 가을에는 낙엽이 많이 떨어져요 = 秋天，许多树叶落到了地上
- 가을에는 곡식을 수확해요 = 谷物在秋季收获
- 다음 주에 태풍이 올 거에요 = 下周会有台风
- 가을에는 일교차가 크기 때문에 겉옷을 항상 준비해야 해요 = 秋天时，你应该随时准备好外套，因为早晚的温度差异可能很大
- 가을에는 날씨가 매우 건조해서 산불이 많이 나요 = 秋季常发生森林火灾，因为天气非常干燥

### 冬季天气

- 날씨가 추워요 = 天气很冷
- 눈이 왔어요 = 正在下雪 / 下过雪
- 눈이 와요 = 正在下雪
- 눈이 많이 싸였어요 = 积了很厚的雪
- 얼음 때문에 길이 미끄러워요 = 由于结冰，路面很滑
- 눈을 치워야 돼요 = 我们得铲雪
- 이방은 난방 중이다 = 该房间正在供暖
- 소금을 뿌려야 돼요 = 我们得往地上撒点盐
- 저는 추운 날씨를 좋아해요 = 我喜欢冷天气
- 저는 걷다가 길이 미끄러워서 넘어졌어요 = 我当时正在走路，结果因为路面湿滑而摔倒了
- 눈이 쌓이고 있어요 = 积雪越积越厚

> 쌓이다“” 用于描述下雪后积雪未消、持续堆积的情况。

- 겨울에 한국 사람들이 문을 왜 안 닫는지 이해가 안 돼요 = 我不明白为什么韩国人冬天不关门

### 春日天气

- 꽃이 피고 있어요 = 花儿盛开了
- 눈이 다 녹았어요 = 雪都融化了
- 날씨가 따듯해지고 있어요 = 天气越来越暖和了
- 한국에는 황사가 중국에서 봄마다 와요 = 每年春天，中国都会有黄沙飘至韩国
- 봄에는 꽃가루 알레르기를 조심해 야 해요 = 春天要小心花粉过敏
- 황사를 피하기 위해 마스크를 써야 해요 = 春天应佩戴口罩，以防黄沙
- 오늘 황사가 심해서 밖에 나가면 안 돼요 = 今天黄沙天气严重，你最好别出门

### 风暴

- 저는 우산을 안 가져왔어요 = 我没带伞
- 우산을 씌워 주세요 = 把伞撑在我头上
- 저는 천둥 치는 소리를 들었어요 = 我听到了雷声
- 비옷을 사야겠어요 = 我得买件雨衣了

### 概述

- 기후변화 때문에 바다 해수면이 높아지고 있어요 = 由于气候变化，海平面正在上升
- 캐나다에서는 공기가 건조해요 = 加拿大的空气很干燥
- 바람이 심하게 불어요 = 风很大
- 날씨가 좀 추워졌어요 = 天气稍微冷了一点
- 날씨는 주말에 추워졌어 = 上周末天气转冷了
- 구름이 그쳤어요 = 云散了
- 가뭄 때문에 물을 아껴 써야 돼요 = 由于干旱，我们需要节约用水

## 韩国的天气

韩国四季分明：夏季、秋季、冬季和春季。秋季和春季通常气候宜人且干燥，正午气温在20–25°C左右。 早春时节，来自中国的“黄沙”（황사）会侵袭韩国，让人不愿出门。建议市民在沙尘浓度较高时不要在户外锻炼，并佩戴口罩。

夏季气温可能升至30°C或更高，且空气潮湿。每年7月都会迎来一个雨季（장마），通常只持续几周。

虽然韩国的冬天很冷，但与加拿大（-20°C且大雪纷飞）等地方相比，还是可以忍受的。让韩国的冬天感觉特别冷的原因在于，这里有不为整个公共建筑供暖的文化——个别商铺会有供暖，但走廊和入口处则没有。在公寓楼里，单个公寓会有供暖，但公共区域则没有。

供暖是通过“温突”**온돌**（ondol）这种地暖系统实现的。历史上，韩国传统民居的热量就是通过地板传导的，这一传统至今仍得以延续。许多韩国人习惯睡在地板上，这也是“温突”系统的一大优点。
