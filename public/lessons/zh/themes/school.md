# （主题）第1单元：第1课——学校

来源：[如何学习韩语——学校](https://www.howtostudykorean.com/theme/school/)

## 引言

大多数学习韩语的外国学习者都是在韩国任教的教师或交换生。即使你不属于这两类人，你很可能也是某处的学生。与学校相关的“class”一词对英语使用者来说比较难——每个含义在韩语中都有不同的词汇：

- **반** = 指的是一群人（例如：“我班上有30名学生”）
- **수업** = 这指的是你所上的课（例如：“我们今天上了5节课”）
- **교실** = 此处指教室（例如：“他在教室里”）
- **교시** = 这指的是某个时间段（通常译为“时期”）

> Example: Our **반** had PE **수업** in the **교실** during second **교시**

## 句子

### 当一名老师

- 저는 선생님이에요 = 我是一名教师
- 저는 영어회화 선생님이에요 = 我是一名英语会话老师
- 저는 영어 선생님이에요 = 我是一名英语老师
- 저는 곧 선생님이 될 것입니다 = 我很快就要当老师了
- 저는 선생님이 되고 싶어요 = 我想当老师
- 저는 언젠가 선생님이 되고 싶어요 = 我希望有一天能成为一名老师
- 담임선생님은 누구예요? = 你的班主任是谁？
- 저는 한국에서 영어 회화선생님이에요 = 我在韩国担任英语口语教师
- 무슨 과목을 가르쳐요? = 你教什么科目？
- 선생님이 왜 되고 싶었어요? = 你为什么想当老师？
- 이 학교에서 언제부터 일했어요? = 你从什么时候开始在这所学校就读的？
- 이 학교 일을 어떻게 구했어요? = 你是怎么找到这个职位的？
- 학교에서 몇 시에 퇴근해요? = 你几点放学？
- 집에 몇 시에 가요? = 你什么时候回家？
- 1주일에 수업을 몇 개 가르쳐요? = 你每周教几节课？
- 하루에 (보통) 수업을 몇 개 가르쳐요? = 你（通常）每天上几节课？
- 이 사람은 우리 학교(의)  영어 원어민 선생님이에요= 此人是我校的母语为英语的教师
- 교장선생님은 선생님들에게 존경 받아요 = 校长深受教师们的尊重
- 학생들은 수업 시간 동안 자고 있었어요 = 学生们上课时都在睡觉
- 그 사람이 선생님인지 아닌지 몰라요 = 我不知道那个人是不是老师
- 내가 선생님이면 학생들을 잘 가르칠 거야 = 如果我是一名教师，我会好好教导学生
- 만약 제가 선생님이라면 학생들에게 존경을 받고 싶을 거에요 = 如果我是一名老师，我希望得到学生的尊重
- 이렇게 많은 내용을 학생들에게 가르치려고 고생을 많이 했어요 = 我付出了很大努力，才把这么多内容教给学生们

### 作为一名学生

- 몇 반이에요? = 你读哪一班？
- 몇 학년이에요? = 你读几年级？
- 저는 1-2이에요 (일학년“-”이반）= 我在1-2班
- 저는 3학년이에요 = 我在三年级
- 저는 내년에 수능을 봐 야 돼요 = 我明年수능得写点东西
- 저는 심심해요 = 我好无聊
- 오늘 수업 시간 동안 뭐 할 거에요? = 今天上课我们要做什么？
- 그 학생은 수업에 집중을 못 해요 = 那个学生上课时无法集中注意力
- 제일 좋아하는 선생님이 누구예요? = 你最喜欢的老师是谁？
- 제일 좋아하는 과목이 뭐예요? = 你最喜欢的科目是什么？
- 다음 수업은 뭐에요? = 下一节课是什么？
- 저는 학교에 친구가 없어요 = 我在学校里没有朋友
- 저는 학교에 친구가 많아요 = 我在学校有很多朋友
- 선생님, 어디 가세요? = 老师，你要去哪儿？
- 저는 그 학생이 어느 대학교를 다니는 지 기억 안 나요 = 我不记得那位学生就读于哪所大学了
- 그 학생이 학교에서 왕따인 것 같아 = 那个学生在学校里大概是个被排挤的人
- 너는 고등학생 같이 보여 = 你看起来像个高中生
- 초등학생과 같아요 = 你就像个小学生一样

### 学习

- 열심히 공부해요! = 努力学习！
- 저는 교감선생님에게서 한국어를 배웠어요 = 我是跟副校长学的韩语
- 선생님,  저는 이 것이 이해가 안 돼요= 老师，我不明白这个
- 저는 선생님이 그 것을 언제 가르친 지 기억 안 나요 = 我不记得老师是什么时候讲的了
- 선생님은 우리를 너무 잘 가르치셨어 = 我们的老师教得特别好
- 수업이 4시쯤에 시작될 예정이에요 = 这节课预计在4:00左右开始
- 제가 공부했을 때 문법만 공부했어요 = 我学习的时候，只学语法
- 제가 공부를 하면 엄마는 电视를 꺼요 = 我学习的时候，妈妈会关掉电视
- (만약)  공부한다면 성공할 거야= 只要努力学习，就一定能成功
- 대학교에 가고 싶다면 열심히 공부해 야 해요 = 如果你想上大学，就必须努力学习
- 내일 공부하러 독서실에 갈래요? = 明天我们去图书馆学习吧？
- 나는 선생님에게 열심히 공부했다고 말했어 = 我告诉老师我学习很努力
- 그는 공부하지 않았다고 했어요 = 他说他没学习
- 선생님은 학생들에게 열심히 공부하라고 했어요 = 老师告诉学生们要努力学习

- 지금 공부를 하고 있기 때문에 너랑 통화하고 싶지 않아 = 我不想和你通电话，因为我现在正在学习
- 저는 내년에 대학교에 갈 것이기 때문에 지금 열심히 공부하고 있어요 = 因为明年我要上大学了，所以我现在正在努力学习
- 요즘에 한국어를 열심히 공부하고 있지만 아직도 잘 말할 수 없어요 = 虽然我最近一直在努力学习韩语，但还是说得不太好

## 韩国学校

学年于3月初开始，分为两个学期。第一学期通常在7月结束，随后是约一个月的暑假。8月开学，一直持续到12月底，之后是为期两个月的寒假。

韩国学生从8岁到13岁（1至6年级）就读小学。小学毕业后，学生升入初中（1至3年级），随后进入为期三年的高中（1至3年级）。 进入顶尖学校的竞争异常激烈。韩国学生为了提高成绩，一直在刻苦学习。

学校上课时间通常从早上8:00左右持续到下午4:00左右，放学后大多数学生会去**학원**补习班继续学习。白天，学生们坐在教室里听课，几乎没有活动或动手实践的机会。 大多数学校都以应试为主，与解题无关的教学往往被视为浪费时间。

一个典型的学期通常会安排一到两次**수행평가**（表现性评估），这些评估通常占最终成绩的30%左右，其余部分则来自期中考试和期末考试。

学生的排名是基于与同龄人的比较，而非绝对分数。高中三年的学业在11月中旬参加（**수능**韩国SAT）考试后结束。大多数大学的录取都基于这一年一度的考试，这给学生带来了极大的压力。
