# （主题）第1单元：第3课——饮食

来源：[如何学习韩语——饮食](https://www.howtostudykorean.com/theme/eating-2/)

## 引言

这里拥有世界上最美味的食物之一，因此学习一些与食物相关的常用词汇和短语总是很有帮助的。

## 句子

### 吃饭时

- 건배! = 干杯！
- 어때요? = 怎么样？
- 이 게 맛있어요 = 这真好吃
- 그 게 안 매워요? = 不辣吗？
- 아직 배고파요? = 你还饿吗？
- 더 먹고 싶어요? = 你还想吃点吗？
- 다 먹을 수 있어요? = 你能吃完吗？
- 더 시킬까요? = 还要再点一些吗？
- 소주를 좀 더 따라 줄까요? = 还要再给你倒点烧酒吗？
- 막걸리를 좋아해요? = 你喜欢吗막걸리？
- 편히 앉아 = 坐得舒服些

> 在韩国，吃饭时坐在地板上是很常见的。先不舒服地跪着，然后被嘱咐可以舒服地坐下，这被视为一种礼貌。

### 决定吃什么 / 进食前

- 뭐 먹을래요? = 我们吃什么好呢？
- 뭐 먹을까요? = 我们吃什么好呢？
- 뭐 마실래요? = 我们喝点什么？
- 밥 먹자! = 开动吧！
- 점심으로 뭐 먹고 싶어요? = 午餐你想吃什么？
- 그 식당이 어디에 있는 지 알아요? = 你知道那家餐厅在哪里吗？
- 맛집을 핸드폰으로 검색해보자 = 让我们用手机找一家好餐厅吧
- 식당은 은행 옆에 있어요 = 这家餐厅就在银行旁边
- 그 식당이 오래되었어요 = 那家餐馆很老了
- 주문할게요 = 我现在就下单
- 주문했어요? = 你下单了吗？
- 뭐 시켰어요? = 你点了什么？
- 맛있는 것을 사 줄게요 = 我会给你买点好吃的
- 제일 맛있는 게 뭐에요? = 什么是最美味的东西？
- 김밥 1줄 주세요 = 请给我一卷紫菜饭

> 줄“” (线) 是 的计数器，김밥因为它的形状像一条线。

- 김밥은 얼마예요? = 紫菜饭多少钱？
- 같이 먹자! = 一起吃饭吧！
- 저는 아직 안 먹었어요 = 我还没吃饭
- 저는 아무것도 먹고 싶지 않아요 = 我什么都不想吃
- 어떤 종류 음식을 먹고 싶어요? = 你最喜欢什么类型的食物？
- 딴 것(을) 먹을래요? = 我们吃点别的吧？

> 用于决定吃什么时，如果朋友推荐了你不喜欢的东西——"那我们换点别的吃吧。"

- 식사 할 거에요? = 你要吃吗？

> 在餐厅里，当你只想点汤或炖菜时，也会说“식사”。”식사만 할 거에요”的意思是“我只点一顿饭”（指特定的餐食）。

### 吃饭时提出要求

- 여기요! = 不好意思！（在餐厅寻求帮助时）
- 물 주세요 = 请给我点水
- 맥주 2잔 주세요 = 请来两杯啤酒
- 물을 갖다 주세요 = 请去给我倒点水
- 물을 이 컵에 따라 주세요 = 请往这个杯子里倒水
- 삼겹살 2개랑 밥 2공기 주세요 = 请来两份三层肉和两份米饭
- 소스를 더 주세요 = 请再给我点酱汁
- 소주 2병 주세요 = 请给我两瓶烧酒
- 조금 더 주세요 = 再多一点点就好，拜托了
- 판을 바꿔 주세요 = 请换个平底锅

> 吃韩式烤肉时常会遇到这种情况，因为肉会把烤盘烤焦。

### 饭后

- 잘 먹었습니다 = “我吃得很饱”（在别人请客或提供餐食后表达礼貌的感谢）
- 잘 먹었어? = “你吃得还好吗？”
- 많이 먹었어? = “你吃得很多吗？”

> 这两种说法通常都是长辈对年轻人说的，用来询问他们饭吃得好不好。

- 점심은 어땠어요? = 午餐怎么样？
- 점심을 먹었어? = 你吃午饭了吗？
- 무엇을 먹었어? = 你吃了什么？
- 식사 하셨어요? = 你吃过饭了吗？（正式）
- 밥 먹었어? = 你吃过饭了吗？（口语）
- 점심으로 뭐 먹었어요? = 你中午吃了什么？
- 저는 아침식사로 밥을 먹었어요 = 我早餐吃了米饭
- 불을 빼 주세요 = 请把火熄灭（烧烤店常见）
- 나는 그만 먹을래 = 我吃完了
- 저는 밥을 많이 먹었어요 = 我吃了好多东西
- 접시를 치워 주세요 = 请把盘子收走
- 계산이요 = 在餐厅结账时说的
- 제가 낼게요 = 我来付钱
- 점심을 누가 냈어요? = 谁请客吃午饭了？
- 저는 밥을 친구랑 저의 어머니랑 먹었어요 = 我和妈妈还有朋友一起吃了饭
- 2(이)차를 갈까요? = 来第二轮吧？

> 韩国人吃完饭后，通常会去另一家餐厅或酒吧继续聚会。

### 概述

- 많이 드세요! = 多吃点 / 祝您用餐愉快（正式）
- 많이 먹어! = 吃个痛快 / 吃好喝好（口语）
- 맛있게 드세요! = 祝您好胃口（正式）
- 김치에 재료가 많이 들어가요 = 泡菜里有很多配料
- 저는 어제 고기를 2번 먹었어요 = 我昨天吃了两次肉
- 저는 지난 번에 돼지고기를 먹었어요 = 上次我们吃了猪肉
- 저는 밥을 5시에 먹을 거에요 = 我将在5:00吃饭
- 저는 사흘 동안 밥을 안 먹었어요 = 我三天没吃米饭了
- 저는 2주일 동안 한식을 안 먹었어요 = 我有两周没吃韩餐了
- 저는 아침식사로 밥을 먹었어요 = 我早餐吃了米饭
- 저는 보통 점심식사로 과일만 먹어요 = 我通常午餐只吃水果
- 저는 빵을 친구랑 먹었어요 = 我和朋友一起吃了面包
- 저는 밥을 먹고 갈 거에요 = 我先吃饭，然后就走
- 저는 엄마가 밥을 먹은 지 안 먹은 지 몰라요 = 我不知道妈妈吃没吃
- 밥을 먹은 지 5분 됐다 = 我已经吃5分钟了

### 餐厅里可能会看到的标语

- 어서 오십시오 = 请进！
- 물은 셀프입니다 = 饮用水请自取
- 반찬을 남기지 마세요 = 别把任何配菜留下来
- 반찬을 먹을 만큼만 가져가세요 = 只取自己能吃完的份量的配菜

> 韩国餐厅会标注食材的原产国。국내산“” 表示国产；对于其他国家，则在“~산”前标注国名（例如： 소고기–  호주산= 牛肉 – 澳大利亚）。

## 韩国人吃什么？

韩国人传统上每餐都会吃米饭。 “**밥**米饭”一词通常被用来泛指一顿饭。每顿饭都由各种**반찬**“配菜”组成。与西方的开胃菜不同，这些配菜반찬是预先制好的食物，通常通过发酵保存较长时间。在家里，韩国人会将这些配菜반찬装在几十个特百惠容器中，存放在冰箱里。

最常见的是반찬 **김치**。大多数人都有一个单独的冰箱，里面只放 김치。
