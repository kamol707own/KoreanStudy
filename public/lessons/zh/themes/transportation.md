# （主题）第1单元：第2课——交通

来源：[如何学习韩语——交通](https://www.howtostudykorean.com/theme/transportation/)

## 引言

大多数移居韩国的外国人并不买车，而是依靠快捷高效的大众交通工具或出租车出行。即使你不居住在韩国，公交车和地铁也随处可见，因此提前掌握一些基础词汇会很有帮助。

## 句子

### 抵达某地

- 오른 쪽으로 가면 돼요 = 向右走
- 왼 쪽으로 가면 돼요 = 向左走
- 거기에 가려면 어느 쪽으로 가야 돼요? = 要想到那里，我该走哪条路？
- 서울역에 가려면 어느 쪽으로 가야 돼요? = 要去首尔站，我该走哪条路？
- 거기에 어떻게 가는 지 알아요? = 你知道怎么去那里吗？
- 거기까지 데려다 줄까요? = 我带你去那里好吗？
- 집까지 데려다 줄게요 = 我送你回家
- 저는 길을 잃었어요 = 我迷路了
- 우리는 길을 건너야 돼요 = 我们得过马路
- 그 식당의 위치를 핸드폰으로 검색할 거에요 = 我用手机查一下这家餐厅的位置
- 그 식당은 은행 건너편에 있어요 = 那家餐馆就在银行对面
- 사당역 4번 출구에서 만나자 = 我们就在萨当站的4号出口见面吧
- 이 길에서 직진하셔요 = 沿着这条路直行
- 저는 거리를 안전하게 건넜어요 = 我安全地过马路了

### 与公交车和地铁相关的情况

- 앉으세요 = 请坐
- 저는 금방 내려요 (내릴 거에요) = 我马上就要下车了
- 교통카드를 어디서 살 수 있어요? = 哪里可以买到公交/地铁卡？
- 교통 카드를 어디서 충전할 수 있어요? = 我在哪里可以给交通卡充值？
- 교통 카드를 잃어버렸어요 = 我把交通卡弄丢了
- 카드에 10,000원 (만원)을 넣어 주세요 = 请往我的卡里充值10,000韩元
- 카드에 10,000원 (만원)을 충전해 주세요 = 请给我的卡充值10,000韩元
- 버스로 가면 지하철보다 더 빨라요 = 如果坐公交车，比坐地铁要快
- 카드를 충전해 주세요 = 请给我的卡充值
- 빨리 타세요 = 快上车！
- 저는 안산으로 가는 막차를 놓쳤어요 = 我错过了开往安山的末班车
- 저는 내일 첫차를 타야 돼요 = 我明天得赶第一班火车
- 막차가 몇 시에 출발해요? = 末班车几点发车？
- 첫차가 몇 시에 출발해요? = 第一班火车几点发车？

### 乘坐公交车

- 거기에 가려면 버스를 타야 돼요 = 要想去那里，你必须坐公交车
- 버스 온다! = 公交车来了！
- 이 버스는 강남에 가요? = 这辆公交车去江南吗？
- 버스가 멈추지 않았어요 = 公交车没停
- 저는 버스정류장에서 버스를 기다리고 있어요 = 我正在公交车站等公交车
- 저는 20분 동안 버스를 기다렸어요 = 我等了20分钟才坐上公交车
- 버스를 동대문에서 타야 돼요 = 你得从东大门站坐公交车
- 다음 정류장에서 내리면 돼요 = 你应该在下一站下车
- 다 다음 정류장에서 내리면 돼요 = 你应该在从现在起两站后下车
- 저는 카드를 안 찍었어요 = 我没有刷卡
- 이 버스의 기본 요금은 2,500원이에요 = 这趟公交车的基本票价是2,500韩元
- 아저씨!문을 열어 주세요! = 先生！请开门。
- 벨을 안 눌렀어요 = 你没按门铃
- 거기 가려면 몇 번 버스를 타야 돼요? = 为了去那里，我应该坐哪路公交车？
- 52번을 타면 돼요 = 你应该乘坐52路公交车
- 버스가 5분 후에 올 거에요 = 公交车5分钟后就到
- 버스 카드가 없어서 현금으로 낼 게요 = 我没带公交卡，所以我要用现金付钱
- 저는 동전이 없어요 = 我没有零钱
- 다음 버스는 저 정류장에서 출발할 거에요 = 下一班公交车将从该站发车
- 버스를 탈 때 카드를 찍어야 되고 내릴 때도 찍어야 돼요 = 上车和下车时都需要刷卡
- 이 버스는 10분마다 와요 = 这趟公交车每10分钟一班

### 乘坐地铁

- 거기에 가려면 전철을 타야 돼요 = 要到那里，你必须乘坐地铁
- 4호선으로 갈아타야 돼요 = 您需要换乘4号线
- 반대로 가야 돼요 = 你需要往相反的方向走
- 어디서 환승해 야 돼요? = 我需要在哪个站换乘？
- 어디서 갈아타 야 돼요? = 我需要在哪个站换乘？
- 홍대에 가려면 몇 호선을 타야 돼요? = 想去弘大，应该坐哪条线？
- 서울역에서 1호선으로 갈아타는 것은 복잡해요 = 在首尔站换乘1号线让人感到困惑
- 저는 벌써 지하철을 타고 있어요 = 我已经在地铁上了

### 在公交车或地铁上听到的或看到的公告

- 전철이 전역에서 출발하였습니다 = 列车已从上一站发车
- 손잡이를 꽉 잡으세요 = 请紧紧抓住把手
- 문에 기대지 마세요 = 请勿倚靠门
- 이번 정류장은 시청 앞입니다.  다음 정류장은 광화문입니다= 此站为市政厅站。下一站是光化门站
- 당고개에 가는 열차가 들어오고 있습니다.  한 걸음을 물러서주시기 바랍니다= 开往丹戈盖的列车即将进站。请往后退
- 이번 역은 서울역. 서울역입니다.  내리실 문은 오른 쪽입니다= 这里是首尔站。右侧车门即将打开
- 동대문으로 가실 분은 이번 역에서 2호선으로 환승하시기 바랍니다 = 前往东大门站的乘客，请在此站换乘2号线

### 乘坐出租车

- 공항으로 가 주세요 = 请送我去机场
- 서울역으로 가 주세요 = 请带我去首尔站
- 여기서 내려 주세요 = 请让我在这里下车
- 서울역까지 가는 데 보통 얼마나 나와요? = 通常去首尔站要花多少钱？
- 지름길로 가주세요 = 请走捷径
- 공항까지 가시나요? = 你要去机场吗？

## 公交车和火车的种类

| 韩语 | 英语 | 注释 |
|--------|---------|-------|
|  일반 버스| 普通公交车 | |
|  좌석버스| 城际快线 | 座位更多；行驶距离更长，连接首尔与郊区 |
|  마을 버스| “村内”公交车 | 车身较小，票价更便宜；行驶距离较短；需要熟悉当地情况 |
|  시외버스| 城际巴士 | |
|  우등버스| 一等座巴士 | 座椅更舒适；城际线路 |
|  리무진或  공항 버스| 机场巴士 | 从机场前往首尔指定地点的舒适接驳巴士 |
|  급행열차| 快车 | 普通地铁，但会跳过部分车站；在高峰时段运行 |
|  공항철도| 机场铁路 | |
